# 멈춰 !

**프로젝트 설명: 돌발 보행자 감지 및 경고 시스템**

천안시 청소년 도시재생 챌린지(U-CAST) — AI 기반 천안시 지역현안 해결 리빙랩  
**5팀 「건영아 잘하자」 / 하드웨어형 산출물**

각 구간의 **시작 IR 센서 + LED 스트립 + 끝 IR 센서**를 하나의 독립 채널로 삼아,
보행자가 차도로 들어서는 순간을 감지해 그 채널의 스트립을 빨간색으로 점멸하고
운전자 경고용 빨간 LED가 점멸하며 부저가 사이렌 소리를 내는 아두이노 장치.

> 채널마다 독립적으로 동작합니다. 그 채널의 시작 IR이 감지되면 그 채널의 스트립만
> 점멸을 시작하고, 같은 채널의 끝 IR이 감지될 때 그 채널만 종료합니다. 이슈 #18에서
> 확정한 구조입니다.

## 3. 최종 MVP 기능

| 구분 | 내용 |
|---|---|
| 진입 감지 | 채널별 시작 IR이 그 채널의 진입을 감지 |
| 종료 감지 | 같은 채널의 끝 IR이 감지되면 그 채널만 종료 |
| 독립 채널 | 채널 1(D8→D4→D10)과 채널 2(D9→`PIN_STRIP_2`→D11)가 서로 독립적으로 동시에 동작 |
| 경고 시작 | 어느 채널이든 시작 IR이 감지되면 그 채널의 경고 시작 |
| 경고 종료 | 같은 채널의 끝 IR이 감지되면 그 채널만 종료. 다른 채널이 남아 있으면 공용 경고는 유지 |
| 운전자 경고 | 활성 채널의 네오픽셀 스트립이 빨간색으로 점멸 + 공용 운전자 경고용 빨간 LED 점멸 |
| 소리 경고 | 하나 이상의 채널이 활성일 때 수동 부저가 800Hz↔1800Hz를 오르내리는 사이렌 소리를 냄(상승·하강 각 0.5초) |
| 수동 시연 | 빨간 버튼 = 두 채널 수동 시작, 초록 버튼 = 두 채널 수동 종료 |

### 초기 검토 후 제외한 기능

워크북 앞부분(2~4장)에 남아 있는 다음 기능은 최종 MVP에 포함하지 않습니다.

- 펜스와 압력센서(FSR)
- 초음파센서
- 횡단보도 방향 계산과 안전한 길 방향 유도
- 흐르는 방향성 LED 애니메이션

경고 중 스트립은 방향 애니메이션 없이, 활성 채널마다 **빨간색으로 점멸**합니다.

## 4. 센서 배치와 알고리즘

### 센서 구성

IR 센서는 개별 디지털 출력 모듈 4개를 사용하며, 각각 별도의 핀을 씁니다.
채널마다 시작 IR과 끝 IR을 한 쌍으로 묶어 **같은 구간**에 놓습니다.

```text
채널 1                                          채널 2
[시작 IR D8]  [LED 스트립1 D4]  [끝 IR D10]     [시작 IR D9]  [LED 스트립2 PIN_STRIP_2]  [끝 IR D11]
   └──── 시작 IR 감지 → 스트립1 점멸 시작 ────┘     └──── 시작 IR 감지 → 스트립2 점멸 시작 ────┘
            끝 IR 감지 → 채널 1만 종료                        끝 IR 감지 → 채널 2만 종료
```

두 채널은 서로 독립이므로 채널 1이 경고 중이어도 채널 2는 별도로 시작·종료할 수 있습니다.

### 상태 전이 (채널별 독립)

상태는 **대기**와 **경고 중** 두 가지이며, "어느 쪽에서 출발했는지"를 기억하는 전역 값
대신 **채널별 활성 플래그**(`channel1Active`, `channel2Active`)를 각각 둡니다.

```text
[채널 N 비활성]
  └─ 시작 IR N 감지 → [채널 N 활성] (그 채널의 스트립만 점멸 시작)

[채널 N 활성]
  ├─ 끝 IR N 감지     → [채널 N 비활성] (그 채널의 스트립만 종료)
  └─ 시작 IR N 재감지 → 활성 유지 (무시)

시스템 전체 상태:
  channel1Active == false && channel2Active == false → STATE_IDLE
  하나 이상 true                                       → STATE_WARNING (공용 LED·부저 동작)
```

논리식으로는 다음과 같습니다.

```text
channel1Active = (시작 IR 1 감지로 true, 끝 IR 1 감지로 false)
channel2Active = (시작 IR 2 감지로 true, 끝 IR 2 감지로 false)

anyChannelActive = channel1Active || channel2Active
```

### 동시 입력 정책

| 상태 | 입력 | 처리 |
|---|---|---|
| 채널 N 비활성 | 같은 채널의 시작·끝 IR 동시 감지 | 시작하지 않음. 시리얼에 `채널N 입력 무시: 시작·끝 센서 동시 감지`를 남깁니다 |
| 채널 N 비활성 | 시작 IR 감지 + 같은 채널 끝 IR이 계속 감지 중 | 모호한 입력으로 보고 시작하지 않음. `채널N 입력 무시: 끝 센서가 이미 감지 중` |
| 채널 N 비활성 | 다른 채널의 시작 IR과 동시 감지 | **정상.** 서로 다른 채널이므로 각각 독립적으로 시작합니다 |
| 채널 N 활성 | 같은 채널의 시작 IR 재감지 | 활성 유지(상태 변경 없음), `채널N 유지: 시작 IR N 재감지` |
| 채널 N 활성 | 같은 채널의 끝 IR 감지 | 그 채널만 종료 |
| 채널 N 활성 | 다른 채널의 끝 IR 감지 | 그 채널에는 영향 없음(각 채널은 자기 로직만 확인) |

빨간 버튼은 채널·센서와 무관한 **강제 시작**이라 두 채널을 모두 켭니다. 초록 버튼은
같은 이유로 두 채널을 모두 끄는 **강제 종료**입니다.

모호 입력 보호는 `IR_PAIR_AMBIGUITY_GUARD`로 끌 수 있지만, 이 로그가 계속 나온다면
**같은 채널의 시작·끝 센서가 서로를 보고 있는 것**이므로 배치부터 고치는 것이 맞습니다.

## 6. 핀 연결표

| 부품 | 핀 | 코드 상수 | 역할 |
|---|:--:|---|---|
| 빨간 경고 LED | D3 | `PIN_WARN_LED` | 공용 운전자 경고용 점멸 |
| LED 스트립 1 DIN | D4 | `PIN_STRIP_1` | 채널 1 경고 조명 |
| LED 스트립 2 DIN | **미정** | `PIN_STRIP_2` | 채널 2 경고 조명 (핀 번호를 직접 지정) |
| 수동 부저 | D5 | `PIN_BUZZER` | 공용 경고음(사이렌) |
| 채널 1 시작 IR | D8 | `PIN_IR_ENTRY_1` | 채널 1 진입 감지 |
| 채널 2 시작 IR | D9 | `PIN_IR_ENTRY_2` | 채널 2 진입 감지 |
| 채널 1 끝 IR | D10 | `PIN_IR_EXIT_1` | 채널 1 종료 감지 |
| 채널 2 끝 IR | D11 | `PIN_IR_EXIT_2` | 채널 2 종료 감지 |
| 빨간 버튼 | A0 | `PIN_BTN_START` | 두 채널 수동 시작 |
| 초록 버튼 | A1 | `PIN_BTN_STOP` | 두 채널 수동 종료 |

A0·A1은 디지털 입력으로 사용합니다(우노에서 각각 디지털 14·15번과 같은 핀).
D0·D1은 시리얼 통신용이라 아무것도 연결하지 않습니다.

> **두 번째 스트립의 핀은 아직 정하지 않았습니다.** `main.ino`의 `PIN_STRIP_2`가
> `0`으로 되어 있고, 이 값이 `0`인 동안에는 두 번째 스트립을 **건너뜁니다.**
> (채널 2의 IR 센서 상태 머신은 그대로 동작합니다.) 스트립 1줄만 꽂아도 그대로
> 동작합니다. 쓸 핀을 정해 그 자리에 번호를 적으면 2줄로 동작합니다. 지금 비어 있는
> 핀: **D2, D6, D7, D12, D13, A2~A5**

### IR 센서 배선

제품마다 선 색과 핀 순서가 다르므로 **제품 설명의 핀 표기를 우선 확인**합니다.

- 채널 1 모듈: `VCC` → 5V, `GND` → GND, `OUT` → 시작 **D8**, 끝 **D10**
- 채널 2 모듈: `VCC` → 5V, `GND` → GND, `OUT` → 시작 **D9**, 끝 **D11**
- 감지 시 출력이 LOW가 아니면 코드의 `IR_ACTIVE_LOW`를 `false`로 변경합니다.
- 이 모듈은 보드에 풀업이 있어 `IR_USE_INTERNAL_PULLUP = false`가 기본입니다.
  값이 떠다니면 `true`로 되돌립니다.

> ⚠ **IR 센서끼리 마주보게 두지 마세요.**
> 사용하는 FC-51 / HW-201 계열 모듈은 송신 LED(투명)와 수신 LED(검정)가 한 보드에
> 같이 붙은 **반사형 장애물 감지** 모듈입니다. 앞으로 쏜 적외선이 물체에 맞고
> 돌아오는 것을 감지하며, 빔이 끊기는 것을 보는 송수신 분리형이 아닙니다.
> 마주보게 두면 서로의 적외선이 상대 수신부에 직접 들어가 **손이 없어도 계속 감지
> 상태로 붙어버립니다.** 모든 센서를 보행자가 지나갈 쪽을 향해 같은 방향으로 두고,
> 모듈 위의 파란 나사로 감지 거리(약 2~30cm)를 맞춥니다. 같은 채널의 시작·끝 IR도
> 서로 마주보지 않게 배치합니다.

### 네오픽셀 배선

- 스트립 1 `DIN` → D4
- 스트립 2 `DIN` → `PIN_STRIP_2`에 적은 핀 (아직 미정)
- 각 데이터선에 330~470Ω 직렬 저항 권장
- 두 스트립 `5V` → 외부 5V 전원
- 두 스트립 `GND` → 외부 전원 GND
- 외부 전원 GND와 Arduino GND를 반드시 공통 연결

### 빨간 LED·부저·버튼

- 빨간 LED: D3 → 220~330Ω → LED `+`, LED `−` → GND
- 부저: `+` → D5, `−` → GND
- 빨간 버튼: 한쪽 → A0, 반대쪽 → GND
- 초록 버튼: 한쪽 → A1, 반대쪽 → GND
- 버튼은 `INPUT_PULLUP`을 사용하므로 외부 풀업 저항이 필요하지 않습니다.

### 전원

네오픽셀은 USB 보조배터리나 정격 5V 어댑터를 사용합니다. 일반 9V 사각 건전지를
네오픽셀에 직접 연결하지 않습니다.

## 7. 코드 구조

`main.ino`는 `delay()` 없이 `millis()` 기반으로 동작합니다.

### 상태

| 상태 | 의미 |
|---|---|
| `STATE_IDLE` | 대기. 두 채널 모두 비활성. 모든 출력 꺼짐 |
| `STATE_WARNING` | 경고 중. 하나 이상의 채널이 활성. 활성 채널의 스트립 점멸, 공용 빨간 LED 점멸, 공용 부저 사이렌 |

`channel1Active`/`channel2Active`가 각 채널의 활성 여부를 독립적으로 기억합니다.
전역 "출발 쪽" 개념은 더 이상 없습니다(이슈 #18).

### 주요 함수

| 함수 | 역할 |
|---|---|
| `detectedEdge()` | IR 신호가 일정 시간 유지된 뒤 감지로 바뀌는 순간만 1회 반환 |
| `buttonPressedEdge()` | 버튼 채터링을 제거하고 누르는 순간만 1회 반환 |
| `startChannel1()` / `startChannel2()` | 해당 채널을 활성화하고, 처음 활성화되는 채널이면 공용 LED·부저도 함께 시작 |
| `stopChannel1()` / `stopChannel2()` | 해당 채널만 비활성화하고 그 스트립을 끄며, 활성 채널이 모두 없어지면 공용 LED·부저도 정지 |
| `startAllChannels()` / `stopAllChannels()` | 빨간·초록 버튼의 두 채널 동시 시작·종료 |
| `applyStrip1()` / `applyStrip2()` | 스트립 하나의 모든 픽셀 색을 정하고 한 번에 전송 |
| `applyActiveChannelStrips()` | 활성 채널의 스트립만 점멸 위상에 맞춰 갱신 |
| `applyWarnLed()` | 공용 빨간 경고 LED를 켜거나 끔 |
| `updateBlinkOutputs()` | `WARNING_BLINK_MS` 간격으로 활성 채널 스트립·공용 LED 점멸 상태 전환 |
| `startBuzzer()` / `stopBuzzer()` | 사이렌을 최저 주파수부터 시작 / 즉시 `noTone()` |
| `sirenFrequencyAt()` | 구간 경과 시간으로 지금 낼 주파수를 정수 연산으로 계산 |
| `updateBuzzerSiren()` | `SIREN_UPDATE_MS`마다 주파수를 갱신하고 구간 끝에서 방향 전환 |
| `logIrValues()` | IR 4개의 핀값·판정과 채널·시스템 상태·출력을 `IR_LOG_INTERVAL_MS`마다 출력 |

### 조정값

| 상수 | 기본값 | 의미 |
|---|:--:|---|
| `PIN_STRIP_2_VALUE` | 0 | **두 번째 스트립 DIN 핀. 0이면 두 번째 스트립을 건너뜀** |
| `STRIP_1_PIXELS`, `STRIP_2_PIXELS` | 10 | 각 스트립에 박힌 낱개 LED 개수 |
| `IR_PAIR_AMBIGUITY_GUARD` | `true` | 같은 채널의 시작·끝이 동시에/계속 감지되면 시작하지 않음 |
| `STRIP_BRIGHTNESS` | 120 | 스트립 밝기 |
| `WARNING_BLINK_MS` | 300 | 활성 스트립·빨간 경고 LED 점멸 간격(부저에는 쓰지 않음) |
| `SIREN_MIN_HZ` | 800 | 사이렌 최저 주파수 |
| `SIREN_MAX_HZ` | 1800 | 사이렌 최고 주파수 |
| `SIREN_SWEEP_MS` | 500 | 상승 한 번 / 하강 한 번에 걸리는 시간 |
| `SIREN_UPDATE_MS` | 25 | 주파수를 다시 계산하는 간격 |
| `IR_LOG_INTERVAL_MS` | 400 | 진단 로그 출력 간격(0이면 주기 출력 끔) |
| `IR_ACTIVE_LOW` | `true` | 감지 시 LOW를 출력하는지 여부(제품별로 다름) |
| `IR_USE_INTERNAL_PULLUP` | `false` | IR 출력에 내부 풀업 사용 여부(모듈에 풀업이 있어 기본은 끔) |
| `IR_CONFIRM_MS` | 60 | 신호 확정 시간 |
| `BUTTON_DEBOUNCE_MS` | 40 | 버튼 채터링 제거 시간 |
| `WARNING_TIMEOUT_MS` | 0 | **워크북 원본 기능이 아닌 선택 설정.** 0이면 채널별 자동 종료 없음 |

`WARNING_TIMEOUT_MS`는 안전 복귀용 선택 기능이며 채널별로 독립 적용됩니다. 워크북의
기획에는 자동 종료가 없으므로 기본값은 0(비활성)이며, 시연 중 종료 입력이 누락되는
상황이 걱정될 때만 0보다 큰 값을 넣어 사용합니다.

### 부저 사이렌

경고 중 부저는 켜졌다 꺼졌다 하지 않고, **소리를 끊지 않은 채 주파수만** 바꿉니다.

```text
800Hz ──(0.5초 동안 상승)──> 1800Hz ──(0.5초 동안 하강)──> 800Hz ─ 반복
```

- 주파수는 `SIREN_UPDATE_MS`(25ms)마다 정수 계산으로 조금씩 갱신합니다.
- `delay()`를 쓰지 않으므로 사이렌이 울리는 중에도 IR 센서와 버튼을 계속 읽습니다.
  사이렌 한가운데에서도 어느 채널의 끝 IR·초록 버튼으로 바로 종료됩니다.
- 활성 채널이 모두 종료되면 즉시 `noTone()`으로 소리를 멈춥니다.
- `tone()`으로 음 높이를 바꾸는 **수동(passive) 부저**가 필요합니다. 능동 부저는
  안에 발진 회로가 있어 정해진 한 음만 나므로 사이렌으로 들리지 않습니다.
- 소리가 거슬리면 `SIREN_MIN_HZ`·`SIREN_MAX_HZ` 간격을 좁히고,
  더 다급하게 하려면 `SIREN_SWEEP_MS`를 줄입니다.

### 시리얼 진단 로그

시리얼 모니터(9600 baud)에 두 종류의 로그가 나옵니다.

| 종류 | 시점 | 예 |
|---|---|---|
| 상태 전환·오류 로그 | 발생 즉시 | `채널1 시작 - 시작 IR 1 감지`, `채널1 입력 무시: 끝 센서가 이미 감지 중` |
| 주기 진단 로그 | `IR_LOG_INTERVAL_MS`(0.4초)마다 | 아래 형식 |

```text
E1(D8)=1 없음  E2(D9)=1 없음  X1(D10)=0 감지  X2(D11)=1 없음  CH1=IDLE CH2=WARNING SYSTEM=WARNING S1=OFF S2=RED LED=ON BUZZER=1240Hz
```

| 항목 | 의미 |
|---|---|
| `E1(D8)=1` | 그 핀의 `digitalRead()` 원시값(0 = LOW, 1 = HIGH) |
| `감지` / `없음` | `IR_ACTIVE_LOW`와 확정 시간까지 적용한 센서별 판정 |
| `CH1=`, `CH2=` | 각 채널의 활성 여부(`WARNING`/`IDLE`) |
| `SYSTEM=` | 두 채널을 합친 시스템 전체 상태 |
| `S1=`, `S2=` | 각 스트립의 지금 출력(`RED`/`OFF`, 미연결이면 `NC`) |
| `LED=`, `BUZZER=` | 공용 출력 상태(부저는 현재 주파수) |

`loop()`마다 찍으면 초당 수천 줄이 나와 읽을 수 없으므로 간격을 둡니다.
`IR_LOG_INTERVAL_MS`를 0으로 하면 주기 로그를 끄고 상태 전환 로그만 남습니다.

이 테스트는 상태 전이와 출력 논리만 확인합니다. IR 모듈의 실제 출력 논리와
부저 음량 같은 값은 실물에서 따로 확인해야 합니다.

### IR 2개 축소판 스케치 (`test/test.ino`)

최종 발표 회로는 IR 센서를 4개 씁니다. 하지만 **지금 가지고 있는 IR 센서는 2개**라서,
가진 부품만으로 먼저 조립하고 알고리즘을 확인할 수 있도록 축소판을 따로 둡니다.
축소판은 채널 1과 같은 구조의 **단일 채널**입니다.

| 항목 | 최종(`main.ino`) 채널 1 | 축소판(`test/test.ino`) |
|---|---|---|
| 시작 IR | D8 | D8 |
| 끝 IR | D10 | **D9** |
| LED 스트립 | 1줄, D4 | 1줄, D4 |
| 빨간 경고 LED | D3 | D3 |
| 부저 | D5 | D5 |
| 빨간 버튼 | A0 | A0 (지금 미연결) |
| 초록 버튼 | A1 | A1 (지금 미연결) |

축소판의 D9는 최종 구성의 **채널 2 시작 IR**과 같은 핀 번호지만 역할이 다릅니다.
축소판에서 D9는 끝 센서, `main.ino`에서 D9는 채널 2의 시작 센서입니다. 최종 구성으로
확장할 때는 축소판의 D9 배선을 그대로 두지 말고, 위 6장 핀 연결표를 기준으로
D8·D9·D10·D11을 다시 배정해야 합니다.

축소판에만 있는 설정도 몇 개 있습니다.

| 상수 | 기본값 | 이유 |
|---|:--:|---|
| `USE_BUTTONS` | `false` | 버튼을 아직 안 달았음. `true`로 바꾸면 A0·A1을 읽음 |
| `WARNING_TIMEOUT_MS` | `10000` | 버튼이 없어 손으로 끌 수 없으므로 10초 뒤 자동 복귀 |
| `STARTUP_SELFTEST` | `true` | 부팅 시 스트립·LED·부저를 한 번 켜서 출력 배선 확인 |
| `IR_LOG_INTERVAL_MS` | `400` | `main.ino`와 같은 값 |

시작·끝 판정 규칙과 동시 입력 정책도 두 파일이 같은 방식으로 동작합니다(축소판은
채널 1개뿐입니다). **알고리즘을 바꿀 때는 두 파일을 함께 고칩니다.**

> `test/test.ino`는 반드시 `test/` 폴더 안에 두어야 합니다. Arduino IDE는 한 스케치
> 폴더 안의 모든 `.ino`를 합쳐 컴파일하므로, `main.ino` 옆에 두면 `setup()`과
> `loop()`가 중복 정의되어 빌드가 실패합니다.

저장소의 회로 자료(아래 두 장)는 Tinkercad에서 IR 센서를 가변저항으로 **대체해**
그린 것입니다. Tinkercad에는 디지털 IR 모듈이 없고 `Adafruit NeoPixel`도 그대로
지원되지 않기 때문이며, 실제 배선은 위 표와 6장 핀 연결표를 따릅니다.

- 회로 구성: [브레드보드 구성 예시(버튼 포함)](docs/images/5조%20회로%20구성%20예시_버튼%20추가.png)
- 스키매틱: [아두이노 스키매틱](docs/images/5조%20아두이노%20스키매틱.pdf)

## 9. 제작 및 시연 순서

상세 절차는 [4차시 제작 가이드](docs/assembly-guide.md)를 따릅니다.

1. 버튼 두 개만 연결해 수동 시작·종료를 확인합니다.
2. 빨간 경고 LED와 수동 부저를 연결합니다.
3. 네오픽셀 스트립(D4)을 연결합니다.
4. 지금 가진 IR 2개를 D8(시작)·D9(끝)에 붙이고 `test/test.ino`로 채널 1 알고리즘을 확인합니다.
5. IR 2개를 더 구하면 D10·D11에 꽂아 4개를 채우고 `main.ino`를 올립니다. 이때 축소판이
   쓰던 D9 배선을 채널 2 시작 IR 위치로 옮기고, D10·D11에 끝 센서를 새로 답니다.
6. 채널 1 진입 → 경고 시작, 채널 1 종료 → 경고 종료를 확인한 뒤, 채널 2도 같은 방식으로
   **독립적으로** 확인하고 마지막으로 두 채널을 동시에 켜고 끄며 서로 간섭하지 않는지 확인합니다.

### 발표 때 보여줄 핵심 장면

- 채널 1 시작 IR 진입 → 스트립 1 점멸 + 공용 빨간 LED 점멸 + 부저 사이렌 → 채널 1 끝 IR 도착 → 채널 1만 종료
- 채널 1이 활성인 상태에서 채널 2 시작 IR 진입 → 채널 1을 끄지 않고 채널 2도 별도로 시작
- 채널 1 종료 후에도 채널 2와 공용 경고가 유지되는 장면, 마지막 채널 종료로 전체가 함께 꺼지는 장면
- 센서가 불안정할 때 빨간·초록 버튼으로 두 채널 시작·종료를 수동 시연

## 10. 알려진 제약

- 같은 채널의 시작·끝이 동시에/계속 감지되면 모호한 입력으로 보고 그 채널을 시작하지 않습니다.
- 여러 사람이 동시에 오갈 때 같은 채널 안에서 개별 보행자를 구분하지 않습니다.
- 직사광선, 설치 각도, 제품별 출력 논리 차이로 오작동할 수 있습니다.
- 반사형 IR 모듈이라 검은색·광택 표면은 적외선을 잘 되돌리지 않아 감지가 약합니다.
- `main.ino`는 채널별 자동 종료가 기본 비활성이므로, 끝 IR이 감지되지 않으면 그 채널의
  경고가 계속 유지됩니다. 이때는 초록 버튼으로 두 채널을 함께 종료합니다.
  (`test/test.ino`는 버튼이 없어 10초 자동 복귀가 기본으로 켜져 있습니다.)
- Tinkercad는 `Adafruit NeoPixel` 라이브러리를 그대로 지원하지 않아 스트립은 실물에서 확인해야 합니다.
- 두 번째 스트립의 실제 DIN 핀이 아직 확정되지 않아 `PIN_STRIP_2`가 `0`인 동안에는
  채널 2의 센서 상태 머신은 동작하지만 스트립 2 출력만 건너뜁니다.
- 이 장치는 무단횡단을 물리적으로 막지 않습니다. 이미 도로에 진입한 보행자를 감지해
  운전자와 보행자에게 알리는 2차 사고 예방 장치입니다(이슈 #6).

문제 발생 시 [문제 해결 가이드](docs/troubleshooting.md)를 확인합니다.

## 12. 설계 변경 기록

### 이슈 #6

최종 명칭:

```text
프로젝트명 : 멈춰 !
프로젝트 설명 : 돌발 보행자 감지 및 경고 시스템
```

기존 "무단횡단 방지 시스템"은 과거 워크북·AI 프롬프트의 원문을 보존해야 하는 위치를
제외하고 현재 프로젝트 공식 명칭으로 사용하지 않습니다.

### 이슈 #18

기존 구현은 4개 IR을 왼쪽/오른쪽으로 묶어 한 개의 전역 경고 상태로 처리했습니다.
최종 의도는 다음과 다릅니다.

```text
IR 시작 1 + IR 끝 1 + 스트립 1 = 채널 1
IR 시작 2 + IR 끝 2 + 스트립 2 = 채널 2
```

각 채널은 독립적으로 작동하며, 향후 채널을 추가할 때도 같은 단위로 확장합니다.
