# 무단횡단 방지 시스템

천안시 청소년 도시재생 챌린지 (U-CAST) — AI 기반 천안시 지역현안 해결 리빙랩
**5팀 「건영아 잘하자」 / 하드웨어형 산출물**

차도 경계선에 접근하는 보행자를 IR 센서로 감지하여, 부저·경고등으로 보행자에게 알리고
차도 위 LED 스트립으로 **운전자에게 "보행자가 건너고 있음"을 경고**하는 아두이노 장치입니다.

## 3. 핵심 기능 (MVP)

| 구분 | 내용 |
|---|---|
| 핵심 기능 1 | IR 적외선 센서로 차도 경계선(위험 구역) 접근 감지 |
| 핵심 기능 2 | 감지 시 부저 경고음 + 빨간색 LED 경고등 작동 |
| 핵심 기능 3 | 차도 위 LED 스트립 2개가 흐르듯 점등되어 운전자에게 횡단 중임을 경고 |
| 상황 종결 | 반대편 IR 센서 한 쌍이 통과를 감지하면 모든 출력 종료 후 대기 복귀 |
| 수동 조작 | 빨간 버튼 = 무단횡단 발생 가정 / 초록 버튼 = 다 건넜다고 가정 (발표 시연용) |

### 제외한 기능

| 제외 기능 | 사유 |
|---|---|
| 초음파 센서 | 역할이 불분명함 |
| 펜스 + 압력 센서(FSR) | 시선이 분산되고, 기댄 것과 넘어가려는 것을 구분하기 어려움 |

> 워크북 5번 부품 목록에는 압력 센서(FSR)가 남아 있었지만,
> 3번 "제외할 기능" 결정에 따라 **코드에서 완전히 제외**했습니다.

### 나중에 개선하고 싶은 기능

- 정류장을 제외한 연석 구간에 펜스를 설치해 도로 진입을 물리적으로 차단
- 정류장에 스크린 도어를 설치해 무단횡단 원천 방지
- TAAS(교통사고분석시스템) 데이터 기반 설치 지점 선정

## 5. 핀 연결표

워크북 "8. 코드 기반 핀 연결표"에 해당하는 표입니다. 4차시 실물 회로 제작에 그대로 사용합니다.

| 부품 | 핀 번호 | 코드 상수 | 역할 |
|---|:--:|---|---|
| 적외선 센서 (IR) 1 | D2 | `PIN_IR_ENTRY_A` | 차도 경계선 진입 감지 (쌍 A) |
| 적외선 센서 (IR) 2 | D3 | `PIN_IR_ENTRY_B` | 차도 경계선 진입 감지 (쌍 B) |
| 적외선 센서 (IR) 3 | D4 | `PIN_IR_EXIT_A` | 반대편 통과 감지 (쌍 A) |
| 적외선 센서 (IR) 4 | D5 | `PIN_IR_EXIT_B` | 반대편 통과 감지 (쌍 B) |
| LED 스트립 1 (네오픽셀) | D6 | `PIN_STRIP_1` | 차도 경고 조명 |
| LED 스트립 2 (네오픽셀) | D7 | `PIN_STRIP_2` | 차도 경고 조명 |
| 빨간색 LED | D8 | `PIN_RED_LED` | 운전자 경고등 |
| 부저 | D9 | `PIN_BUZZER` | 경고음 |
| 빨간색 버튼 | D10 | `PIN_BTN_RED` | 수동 발동 |
| 초록색 버튼 | D11 | `PIN_BTN_GREEN` | 수동 종결 |

> 워크북에는 IR 센서가 D2 한 줄만 적혀 있고 "센서가 여러 개라 핀 번호가 더 필요하다"고 메모되어 있었습니다.
> 그래서 IR 센서 4개를 **D2~D5**로 확장했고, 스트립이 2개이므로 두 번째 스트립을 **D7**에 추가했습니다.
> 워크북 표의 빨간색 LED(D8) / 부저(D9) 배정은 그대로 따랐습니다.

### 배선 방법

**IR 센서 4개 (각각)**
- `VCC` → 아두이노 `5V`
- `GND` → 아두이노 `GND`
- `OUT` → D2 / D3 / D4 / D5

**LED 스트립 2개 (각각)**
- `DIN` → D6 / D7
- `5V` → **외부 전원 +5V** (아두이노 5V 핀에서 직접 뽑지 말 것)
- `GND` → 외부 전원 GND **및** 아두이노 GND (반드시 공통 접지)

**빨간색 LED**
- D8 → 220~330Ω 저항 → LED 긴 다리(+)
- LED 짧은 다리(−) → GND

**부저**
- `+` → D9, `−` → GND

**버튼 2개 (각각)**
- 한쪽 다리 → D10 / D11, 반대쪽 다리 → GND
- 코드에서 `INPUT_PULLUP`을 쓰므로 별도 저항이 필요 없습니다.

> ⚠️ **전원 주의**: 네오픽셀은 픽셀 1개당 최대 60mA까지 소모합니다. 아두이노 5V 핀만으로는
> 부족하므로 반드시 외부 전원을 쓰고, 외부 전원 GND와 아두이노 GND를 연결하세요.
> 밝기(`STRIP_BRIGHTNESS`)를 낮추면 소비 전류도 함께 줄어듭니다.

## 6. 동작 흐름

```
[대기 상태]
    │  보행자가 인도 위를 정상 이동 → 부저·LED 모두 꺼짐
    │
    │  ◀── 자동: 진입 IR 센서 쌍(D2/D3) 감지
    │  ◀── 수동: 빨간색 버튼(D10)
    ▼
[경고 상태]
    │  · 부저 경고음 (삐- 쉬고 삐-)
    │  · 빨간색 LED 점멸
    │  · 차도 LED 스트립 2개가 횡단보도 방향으로 흐르듯 점등
    │
    │  ◀── 자동: 통과 IR 센서 쌍(D4/D5) 감지
    │  ◀── 수동: 초록색 버튼(D11)
    │  ◀── 또는 60초 경과 (안전 자동 복귀)
    ▼
[대기 상태로 복귀]
```

경고가 시작된 뒤 **최소 3초** 동안은 종료 신호를 무시합니다.
진입 센서가 통과 센서까지 함께 건드려서 경고가 곧바로 꺼지는 것을 막기 위한 장치입니다.

## 7. 기준값 조정 가이드

수정이 필요한 값은 **전부 `main.ino` 상단 `[설정]` 구역의 상수**로 빠져 있습니다.
아래 표의 상수 값만 바꾸면 되고, 그 아래 로직 코드는 건드릴 필요가 없습니다.

### 부품을 받은 뒤 가장 먼저 확인할 값

| 상수 | 기본값 | 언제 바꾸나 |
|---|:--:|---|
| `STRIP1_PIXELS` / `STRIP2_PIXELS` | 10 | **실제 스트립의 LED 개수로 반드시 수정.** 개수가 다르면 일부가 안 켜지거나 애니메이션이 이상해집니다 |
| `IR_ACTIVE_LOW` | `true` | 아무것도 없는데 계속 감지된다면 `false`로. 대부분의 IR 모듈은 감지 시 LOW라 기본값 그대로면 됩니다 |
| `STRIP_BRIGHTNESS` | 120 | 너무 어두우면 올리고, 전원이 부족해 깜빡이면 내립니다 (0~255) |

### 감지가 잘 안 될 때

| 상수 | 기본값 | 조정 방향 |
|---|:--:|---|
| `ENTRY_REQUIRE_BOTH` | `false` | `false` = 쌍 중 하나만 감지돼도 발동(잘 잡힘) / `true` = 둘 다 감지돼야 발동(오작동 적음) |
| `ENTRY_CONFIRM_MS` | 120 | 반응이 느리면 줄이고, 헛감지가 잦으면 늘립니다 |
| `EXIT_REQUIRE_BOTH` | `false` | 통과 감지 쌍에 대한 같은 옵션 |
| `EXIT_CONFIRM_MS` | 200 | 통과 감지 확정 시간 |

> IR 센서 모듈 뒷면의 **파란색 가변저항(포텐셔미터)** 으로 감지 거리를 조절할 수 있습니다.
> 워크북 설계 기준은 **30cm 이내 접근 시 감지**입니다. 코드보다 이 손잡이를 먼저 돌려 보세요.

### 경고 동작을 바꾸고 싶을 때

| 상수 | 기본값 | 설명 |
|---|:--:|---|
| `WARNING_MIN_MS` | 3000 | 경고 최소 유지 시간(ms). 경고가 너무 빨리 꺼지면 늘립니다 |
| `WARNING_TIMEOUT_MS` | 60000 | 종료 신호가 없을 때 자동 복귀까지의 시간(ms). `0`이면 자동 복귀 안 함 |
| `BUZZER_FREQ_HZ` | 2000 | 경고음 높낮이(Hz). `0`이면 부저를 쓰지 않음 |
| `BUZZER_ON_MS` / `BUZZER_OFF_MS` | 200 / 200 | 삐- 소리와 쉬는 시간. 둘 다 줄이면 더 다급하게 들립니다 |
| `RED_LED_BLINK` | `true` | `false`면 깜빡이지 않고 계속 켜짐 |
| `RED_LED_BLINK_MS` | 300 | 깜빡이는 간격(ms) |

### LED 스트립 연출을 바꾸고 싶을 때

| 상수 | 기본값 | 설명 |
|---|:--:|---|
| `WARN_COLOR_R/G/B` | 255 / 0 / 0 | 스트립 색상. 기본은 빨간색 |
| `COMET_LENGTH` | 4 | 흐르는 불빛의 꼬리 길이. 클수록 길게 늘어짐 |
| `ANIM_STEP_MS` | 60 | 한 칸 이동 시간(ms). 작을수록 빠르게 흐름 |
| `STRIP1_REVERSE` / `STRIP2_REVERSE` | `false` | 흐르는 방향이 반대면 `true`로 |

### 기타

| 상수 | 기본값 | 설명 |
|---|:--:|---|
| `BUTTON_DEBOUNCE_MS` | 40 | 버튼이 한 번 눌렀는데 여러 번 눌린 것처럼 동작하면 늘립니다 |
| `SERIAL_DEBUG` | `true` | 시리얼 모니터(9600 baud)로 상태 출력 |

## 8. 업로드 방법

1. Arduino IDE 실행
2. **스케치 → 라이브러리 포함하기 → 라이브러리 관리** 에서 `Adafruit NeoPixel` 검색 후 설치
3. **툴 → 보드**: `Arduino Uno` 선택
4. **툴 → 포트**: 연결된 포트 선택
5. `main.ino` 열고 업로드
6. **툴 → 시리얼 모니터** (9600 baud)에서 상태 로그 확인

## 9. 발표 시연 방법

센서 감지가 불안정한 현장에서도 시연이 되도록, 두 버튼이 센서와 **완전히 같은 로직**을 실행합니다.

1. 전원을 켜면 대기 상태 (모든 출력 꺼짐)
2. **빨간색 버튼**을 누른다 → 무단횡단이 발생했다고 가정
   → 부저 경고음 + 빨간색 LED 점멸 + 차도 스트립 2개 흐름 점등
3. 3초 이상 경고 상태를 보여준다
4. **초록색 버튼**을 누른다 → 보행자가 다 건넜다고 가정
   → 모든 출력이 꺼지고 대기 상태로 복귀

자동 시연은 손이나 물체로 D2/D3 센서 앞을 가리면 발동하고, D4/D5 센서 앞을 가리면 종료됩니다.

## 10. 알려진 제약

- **Tinkercad에서는 그대로 동작하지 않습니다.** Tinkercad 시뮬레이터는 `Adafruit_NeoPixel`
  라이브러리를 지원하지 않습니다. 시뮬레이터로 로직만 확인하려면 스트립을 일반 LED로 바꾼
  별도 스케치가 필요합니다. (아직 작성하지 않음)
- 네오픽셀 출력 중에는 인터럽트가 잠깐 꺼지므로, 부저 소리에 아주 미세한 흔들림이 있을 수
  있습니다. 실제 청감에는 영향이 없습니다.
