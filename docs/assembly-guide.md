# 4차시 제작 가이드 — IR 브레이크빔 양방향 경고 시스템

회로를 한 번에 모두 연결하지 않고 **입력 → 단순 출력 → 스트립 → 실제 센서** 순서로 제작합니다.
핀 배정은 [README 6. 핀 연결표](../README.md#6-핀-연결표)와 `main.ino` 상단 설정값을 기준으로 합니다.

- 전체 배선도: [브레드보드 배선도](images/breadboard-wiring.svg)
- 상태 전이: [동작 상태 흐름도](images/state-flow.svg)

---

## 0. 부품 확인

| 항목 | 확인 내용 |
|---|---|
| IR 종류 | 반사형 장애물 센서가 아니라 **송신부·수신부가 분리된 IR 브레이크빔 2세트**인지 확인 |
| 수신부 OUT | 빔이 끊겼을 때 HIGH인지 LOW인지 제품 설명 또는 시리얼 출력으로 확인 |
| 부저 | `tone()`을 사용하는 수동(passive) 부저인지 확인 |
| 스트립 픽셀 수 | 각 스트립 LED 개수를 세어 `STRIP1_PIXELS`, `STRIP2_PIXELS`에 입력 |
| 외부 전원 | 정격 5V 보조배터리 또는 어댑터 준비. 9V 사각 건전지 직접 연결 금지 |
| 라이브러리 | Arduino IDE에서 `Adafruit NeoPixel` 설치 |
| 안전 | 배선을 바꿀 때 Arduino USB와 외부 전원을 모두 분리 |

제품마다 IR 브레이크빔 선 색이 다를 수 있으므로 색상만 보고 연결하지 말고
`VCC`, `GND`, `OUT` 표기를 확인합니다.

## 1단계 — 버튼으로 알고리즘 먼저 확인

빨간 버튼과 초록 버튼은 시작·종료 버튼이 아닙니다.

- 빨간 버튼(D10): **왼쪽 IR 빔이 끊긴 상황**을 모의
- 초록 버튼(D11): **오른쪽 IR 빔이 끊긴 상황**을 모의

### 배선

1. 빨간 버튼 한쪽 → D10, 반대쪽 → GND
2. 초록 버튼 한쪽 → D11, 반대쪽 → GND
3. `main.ino`를 업로드하고 시리얼 모니터를 9600 baud로 엽니다.

버튼은 `INPUT_PULLUP`을 사용하므로 별도 풀업 저항이 필요하지 않습니다.

### 확인 시나리오

| 순서 | 예상 로그 |
|---|---|
| 빨간 버튼 | `왼쪽 → 오른쪽 횡단 시작` |
| 0.8초 이상 기다린 뒤 초록 버튼 | `오른쪽 인도 도착 감지` 후 대기 복귀 |
| 초록 버튼 | `오른쪽 → 왼쪽 횡단 시작` |
| 0.8초 이상 기다린 뒤 빨간 버튼 | `왼쪽 인도 도착 감지` 후 대기 복귀 |

같은 버튼을 횡단 중 다시 누르면 반복 입력으로 무시되는 것이 정상입니다.

## 2단계 — 표지판 LED와 부저 연결

### 표지판 LED

MVP에서는 반투명한 `보행자 주의` 표지판 뒤에 일반 빨간 LED 1개 또는
저항이 내장된 빨간 LED 모듈 1개를 배치합니다.

- 일반 LED: D8 → 220~330Ω 저항 → LED 긴 다리(+)
- LED 짧은 다리(−) → GND

일반 LED 여러 개를 D8에 직접 병렬 연결하지 않습니다. 여러 개가 필요하면 각 LED에 저항을
사용하고 트랜지스터 또는 MOSFET 구동 회로를 별도로 설계합니다.

### 부저

- 부저 `+` → D9
- 부저 `−` → GND

### 확인

빨간 버튼을 누르면 표지판 LED가 약 0.3초 간격으로 점멸하고 부저가 간헐적으로 울려야 합니다.
초록 버튼을 누르면 전체 출력이 꺼집니다.

## 3단계 — 도로 LED 스트립 연결

스트립은 횡단보도 방향 유도가 아니라 **도로 위 보행자 존재 경고**입니다.
경고 상태에서 두 스트립 전체가 빨간색으로 동시에 점멸합니다.

### 스트립 1

1. DIN → D6
2. 데이터선에 330~470Ω 직렬 저항 권장
3. 5V → 외부 5V 전원
4. GND → 외부 전원 GND
5. 외부 전원 GND ↔ Arduino GND 공통 연결
6. `STRIP1_PIXELS`를 실제 개수로 수정

버튼 시나리오로 스트립 1이 표지판 LED와 함께 점멸하는지 확인합니다.

### 스트립 2

스트립 1이 정상일 때 같은 방식으로 DIN만 D7에 연결하고 `STRIP2_PIXELS`를 수정합니다.

전원이 부족하면 색이 변하거나 Arduino가 재부팅될 수 있습니다. 이때
`STRIP_BRIGHTNESS`를 낮추고 외부 전원 용량을 확인합니다.

## 4단계 — IR 브레이크빔 2세트 연결

### 왼쪽 인도 세트

- 송신부 VCC → 5V
- 송신부 GND → GND
- 수신부 VCC → 5V
- 수신부 GND → GND
- 수신부 OUT → D2

### 오른쪽 인도 세트

- 송신부 VCC → 5V
- 송신부 GND → GND
- 수신부 VCC → 5V
- 수신부 GND → GND
- 수신부 OUT → D3

### 설치 방향

```text
왼쪽 인도                     차도                     오른쪽 인도
송신부 ●────────● 수신부    LED 스트립 1·2    송신부 ●────────● 수신부
          보행자 통과선                                  보행자 통과선
```

각 송신부와 수신부는 **같은 인도 쪽 통과 구간을 사이에 두고 서로 마주 보게** 설치합니다.
빔이 도로 전체를 가로지르거나 차량을 감지하도록 설치하지 않습니다.

### 정렬 순서

1. 송신부와 수신부 높이를 맞춥니다.
2. 아무것도 가리지 않을 때 수신부 상태 LED 또는 시리얼 값이 안정적인지 확인합니다.
3. 손이나 보행자 모형으로 빔을 끊었을 때 값이 바뀌는지 확인합니다.
4. 반대로 동작하면 `IR_ACTIVE_LOW`를 변경합니다.
5. 오픈 컬렉터 출력이 불안정하면 `IR_USE_INTERNAL_PULLUP = true`를 유지합니다.
6. 빔이 잠깐 흔들려 오작동하면 `IR_CONFIRM_MS`를 늘립니다.

## 5단계 — 전체 양방향 시연

### 왼쪽에서 오른쪽

1. 왼쪽 빔 차단
2. 차도 스트립·표지판 LED·부저 작동
3. 0.8초 이상 후 오른쪽 빔 차단
4. 모든 출력 종료

### 오른쪽에서 왼쪽

1. 오른쪽 빔 차단
2. 같은 경고 출력 작동
3. 0.8초 이상 후 왼쪽 빔 차단
4. 모든 출력 종료

### 비상 시연

실제 센서가 현장 조명이나 정렬 문제로 작동하지 않으면 빨간 버튼과 초록 버튼으로
동일한 왼쪽·오른쪽 감지 입력을 모의합니다.

## 모형 배치 권장안

```text
┌──────── 왼쪽 인도 ────────┐     ┌──────── 오른쪽 인도 ────────┐
│ IR 송신 ●──────● IR 수신  │     │ IR 송신 ●──────● IR 수신  │
└────────────┬───────────────┘     └────────────┬───────────────┘
             │            도로                 │
        ═════╪════ LED 스트립 1 ═══════════════╪═════
        ═════╪════ LED 스트립 2 ═══════════════╪═════
             │                                  │
      [보행자 주의 표지판]               [실제 적용 시 반대 방향 표지판]
```

MVP에서는 표지판 1개만 제작해도 되지만, 실제 양방향 도로 적용 시 차량 진행 방향마다
표지판을 각각 설치해야 합니다.

## 제작 후 기록

| 항목 | 기록 내용 |
|---|---|
| IR 제품명 | 송신부·수신부 핀 배열과 빔 차단 시 출력값 |
| 스트립 픽셀 수 | `STRIP1_PIXELS`, `STRIP2_PIXELS` 최종값 |
| 전원 | 사용한 5V 전원의 정격 전류 |
| 조정값 | `IR_ACTIVE_LOW`, `IR_CONFIRM_MS`, 밝기와 점멸 간격 |
| 촬영 | 대기, 왼→오, 오→왼, 버튼 비상 시연, 회로와 센서 정렬 사진 |
