# 4차시 제작 가이드 — 양방향 IR 경고 시스템

회로를 한 번에 모두 연결하지 않고 **버튼 → 단순 출력 → 스트립 → IR 센서** 순서로 제작합니다.

> **지금은 IR 센서 2개 · 스트립 1줄뿐이고 버튼도 없습니다.** 4단계까지는
> `test/test.ino`(축소판)로 진행하고, 부품을 채운 뒤 `main.ino`로 바꿔 올립니다.
> 축소판이 쓰는 핀은 최종 구성의 부분집합이라 **배선을 다시 하지 않아도 됩니다.**

> **양방향입니다.** 어느 쪽 연석에서 출발하든 동작하며, 먼저 감지된 쪽을 출발 쪽으로
> 기억했다가 **반대편**이 감지될 때 경고를 끝냅니다.

> ⚠ **IR 센서를 서로 마주보게 두지 마세요.** FC-51 / HW-201 계열은 송신 LED와
> 수신 LED가 한 보드에 같이 붙은 **반사형** 모듈이라, 마주보게 두면 서로의 적외선이
> 상대 수신부에 직접 들어가 계속 감지 상태로 붙습니다. 모든 센서를 보행자가 지나갈
> 쪽을 향해 **같은 방향으로** 두세요.
핀 배정은 [README 6. 핀 연결표](../README.md#6-핀-연결표)와 `main.ino` 상단 설정값을 기준으로 합니다.

- 전체 배선도: [브레드보드 배선도](images/breadboard-wiring.svg)
- 상태 전이: [동작 상태 흐름도](images/state-flow.svg)

## 0. 부품 확인

| 항목 | 확인 내용 |
|---|---|
| IR 개수 | 최종 구성은 진입 2개 + 통과 2개, 총 **4개**. 지금 몇 개가 있는지 먼저 확인 |
| IR 출력 | 감지했을 때 HIGH인지 LOW인지 제품 설명 또는 시리얼 출력으로 확인 |
| 부저 | `tone()`을 사용하는 수동(passive) 부저인지 확인. 능동 부저면 소리 높이가 고정됨 |
| 스트립 개수 | 최종 구성은 **2줄**. 두 번째 스트립 DIN 핀은 `PIN_STRIP_2`에 직접 지정 |
| 스트립 픽셀 수 | LED 개수를 세어 `STRIP_1_PIXELS`, `STRIP_2_PIXELS`에 입력 (현재 10) |
| 외부 전원 | 정격 5V 보조배터리 또는 어댑터 준비. 9V 사각 건전지 직접 연결 금지 |
| 라이브러리 | Arduino IDE에서 `Adafruit NeoPixel` 설치 |
| 안전 | 배선을 바꿀 때 Arduino USB와 외부 전원을 모두 분리 |

제품마다 IR 센서 선 색이 다를 수 있으므로 색상만 보고 연결하지 말고
`VCC`, `GND`, `OUT` 표기를 확인합니다.

## 1단계 — 버튼으로 알고리즘 먼저 확인

버튼은 방향이나 특정 센서를 모의하지 않습니다.

- 빨간 버튼(A0): **경고 수동 시작**
- 초록 버튼(A1): **경고 수동 종료**

버튼이 아직 없다면 이 단계를 건너뛰고 2단계로 갑니다. `test/test.ino`의
`USE_BUTTONS`가 `false`라 버튼 핀을 아예 읽지 않으므로 오작동하지 않습니다.
버튼을 달면 `USE_BUTTONS`를 `true`로 바꾸세요.

### 배선

1. 빨간 버튼 한쪽 → A0, 반대쪽 → GND
2. 초록 버튼 한쪽 → A1, 반대쪽 → GND
3. 스케치를 업로드하고 시리얼 모니터를 9600 baud로 엽니다.
   (IR 2개 단계에서는 `test/test.ino`, IR 4개를 채운 뒤에는 `main.ino`)

버튼은 `INPUT_PULLUP`을 사용하므로 별도 풀업 저항이 필요하지 않습니다.
A0·A1은 아두이노 우노에서 디지털 입력으로도 사용할 수 있는 핀입니다.

### 확인 시나리오

| 순서 | 예상 로그 |
|---|---|
| 빨간 버튼 | `상태: 경고 시작 - 빨간 버튼 수동 시작` |
| 경고 중 빨간 버튼 다시 | `경고 유지: 빨간 버튼 재입력` |
| 초록 버튼 | `상태: 대기 복귀 - 초록 버튼 수동 종료` |
| 대기 중 초록 버튼 | 아무 로그도 나오지 않음(정상) |

버튼을 길게 눌러도 시작 또는 종료는 한 번만 처리됩니다.

## 2단계 — 빨간 경고 LED와 부저 연결

### 빨간 경고 LED

운전자에게 보이도록 반투명 표지판 뒤에 빨간 LED 1개 또는 저항이 내장된
빨간 LED 모듈 1개를 배치합니다.

- 일반 LED: D3 → 220~330Ω 저항 → LED 긴 다리(+)
- LED 짧은 다리(−) → GND
- RGB LED를 쓸 경우 빨간색 핀에만 신호를 연결합니다.

일반 LED 여러 개를 D3에 직접 병렬 연결하지 않습니다. 여러 개가 필요하면 각 LED에 저항을
사용하고 트랜지스터 또는 MOSFET 구동 회로를 별도로 설계합니다.

### 부저

- 부저 `+` → D5
- 부저 `−` → GND

### 확인

빨간 버튼을 누르면 빨간 LED와 부저가 약 0.3초(`WARNING_BLINK_MS`) 간격으로
**함께** 점멸해야 합니다. 초록 버튼을 누르면 전체 출력이 꺼집니다.

## 3단계 — LED 스트립 연결

스트립은 최종 **2줄**입니다. 방향 유도용이 아니라 경고용이며,
경고 상태에서 스트립 전체가 빨간색으로 켜지고 흐르는 애니메이션은 없습니다.

### 스트립 1

1. DIN → D4
2. 데이터선에 330~470Ω 직렬 저항 권장
3. 5V → 외부 5V 전원
4. GND → 외부 전원 GND
5. 외부 전원 GND ↔ Arduino GND 공통 연결
6. 스트립의 낱개 LED 개수를 세어 `STRIP_1_PIXELS`가 맞는지 확인 (현재 값 10)

빨간 버튼을 눌러 스트립 전체가 빨간색으로 켜지는지 확인합니다.
뒷부분 몇 개가 안 켜지면 `STRIP_1_PIXELS`가 실물보다 작은 것입니다.

### 스트립 2 (나중에)

두 번째 스트립이 들어오면 **쓸 핀을 먼저 정하고** `main.ino`의 `PIN_STRIP_2`에
그 번호를 적습니다. 비어 있는 핀은 D2, D6, D7, D12, D13, A2~A5입니다.

`PIN_STRIP_2`가 `0`인 동안에는 두 번째 스트립을 건너뛰므로, 1줄만 꽂아도
그대로 동작합니다. 배선은 스트립 1과 같은 방식입니다.

전원이 부족하면 색이 변하거나 Arduino가 재부팅될 수 있습니다. 이때
`STRIP_BRIGHTNESS`를 낮추고 외부 전원 용량을 확인합니다.

D0·D1은 시리얼 통신에 쓰이므로 아무것도 연결하지 않습니다.

## 4단계 — IR 센서 연결

### 4-A. 지금(IR 2개) — `test/test.ino`

- 왼쪽 연석 IR: `VCC` → 5V, `GND` → GND, `OUT` → **D8**
- 오른쪽 연석 IR: `VCC` → 5V, `GND` → GND, `OUT` → **D10**

두 센서를 도로 모형의 **양쪽 연석**에 두고, 어느 쪽에서 손을 넣어도 경고가 시작되고
반대편에서 손을 넣으면 꺼지는지 확인합니다. 방향을 바꿔서도 해 보세요.

### 4-B. 최종(IR 4개) — `main.ino`

센서 2개를 더 구하면 **비어 있는 D9·D11에 꽂기만** 합니다. 기존 선은 그대로 둡니다.

- 왼쪽 IR 1: `OUT` → **D8**  (그대로)
- 왼쪽 IR 2: `OUT` → **D9**  (추가)
- 오른쪽 IR 1: `OUT` → **D10** (그대로)
- 오른쪽 IR 2: `OUT` → **D11** (추가)

모든 모듈은 `VCC` → 5V, `GND` → GND로 공통 연결합니다.
꽂은 뒤 `main.ino`를 업로드합니다.

### 설치 위치

모든 센서가 **같은 방향**을 봅니다. 마주보게 두면 서로 간섭합니다.

```text
     왼쪽 연석                차도                오른쪽 연석
[IR D8]  [IR D9]        [LED 스트립]        [IR D10] [IR D11]
   ↑        ↑                                   ↑        ↑
        어느 쪽이든 먼저 감지되면 경고 시작
              반대편이 감지되면 경고 종료
```

왼쪽/오른쪽은 그냥 **서로 반대편 연석**이라는 뜻입니다. 어느 쪽을 왼쪽이라 부르든
상관없고, 두 묶음이 도로를 사이에 두고 마주 놓이기만 하면 됩니다.
(센서 **방향**은 마주보게 하지 말고 각자 보행자가 지나갈 쪽을 향하게 둡니다.)

각 연석의 센서는 그쪽 보도에서 차도로 들어서는 구간을 감지하도록 설치합니다.
양쪽 센서를 서로 너무 가깝게 두면 두 신호가 동시에 감지되어 경고가 시작되지 않을 수
있습니다(모호 입력 보호). 도로 폭만큼 충분히 떨어뜨리세요.

### 확인 순서

0. `test/test.ino`는 두 IR의 핀값과 판정을 0.4초마다 시리얼에 찍습니다.
   손을 치웠을 때 둘 다 `없음`이 되도록 모듈 위의 파란 나사를 먼저 맞춥니다.
1. 아무것도 감지되지 않을 때 상태 변화 로그가 나오지 않는지 확인합니다.
2. 왼쪽 IR 앞에 손을 대면 `상태: 경고 시작 - 왼쪽에서 차도 진입`이 나와야 합니다.
3. 손을 계속 대고 있어도 로그가 반복되지 않아야 합니다.
4. 오른쪽 IR 앞에 손을 대면 `상태: 대기 복귀 - 반대편 도착 - 횡단 완료`가 나옵니다.
4-2. 이번엔 오른쪽부터 시작해 왼쪽으로 끝내 보세요. 똑같이 동작해야 합니다.
4-3. 경고 중에 **출발한 쪽** 앞에서 손을 흔들면 `경고 유지: 출발한 쪽 재감지`가
   나오고 경고가 꺼지지 않아야 합니다.
5. 반대로 동작하면 `IR_ACTIVE_LOW`를 변경합니다.
6. 출력이 불안정하면 `IR_USE_INTERNAL_PULLUP`을 `true`로 바꿉니다.
7. 잠깐 스쳐도 발동하면 `IR_CONFIRM_MS`를 늘리고, 빠르게 지나갈 때 안 잡히면 줄입니다.
8. `입력 무시: 양쪽이 동시에 감지됨`이나 `... 계속 감지 중`만 나오면 **두 센서가
   서로를 보고 있는 것**입니다. 각자 보행자 쪽을 향하도록 방향을 돌립니다.

## 5단계 — 전체 시연

1. 대기 상태에서 모든 출력이 꺼져 있는지 확인
2. 왼쪽 진입 → 스트립 전체 빨간색 + 빨간 LED·부저 점멸 → 오른쪽 도착 → 종료
3. **반대 방향**: 오른쪽 진입 → 왼쪽 도착 → 종료
4. 각 연석의 2번 센서(D9·D11)로도 같은 동작이 되는지 확인
5. 경고 중 출발한 쪽 재감지로는 꺼지지 않는지 확인

### 수동 시연

실제 센서가 현장 조명이나 설치 문제로 작동하지 않으면 빨간 버튼으로 경고를 시작하고
초록 버튼으로 종료하는 수동 시연을 사용합니다.

## 모형 배치 권장안

```text
┌───── 왼쪽 연석 ──────┐                    ┌───── 오른쪽 연석 ─────┐
│  IR D8      IR D9    │                    │  IR D10     IR D11   │
└───────────┬───────────┘                    └───────────┬───────────┘
            │               도로                         │
       ═════╪════ LED 스트립 1 · D4 (LED 10개) ══════════╪═════
       ═════╪════ LED 스트립 2 · 핀 미정 ════════════════╪═════
            │                                            │
     [빨간 경고 LED / 표지판]                       [부저]
```

MVP에서는 표지판 1개만 제작해도 되지만, 실제 양방향 도로 적용 시 차량 진행 방향마다
표지판을 각각 설치해야 합니다.
