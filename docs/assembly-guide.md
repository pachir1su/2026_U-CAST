# 4차시 제작 가이드 — 진입·통과 IR 경고 시스템

회로를 한 번에 모두 연결하지 않고 **버튼 → 단순 출력 → 스트립 → IR 센서** 순서로 제작합니다.
핀 배정은 [README 6. 핀 연결표](../README.md#6-핀-연결표)와 `main.ino` 상단 설정값을 기준으로 합니다.

- 전체 배선도: [브레드보드 배선도](images/breadboard-wiring.svg)
- 상태 전이: [동작 상태 흐름도](images/state-flow.svg)

---

## 0. 부품 확인

| 항목 | 확인 내용 |
|---|---|
| IR 개수 | 진입 감지용 2개와 통과 감지용 2개, 총 **4개**가 있는지 확인 |
| IR 출력 | 감지했을 때 HIGH인지 LOW인지 제품 설명 또는 시리얼 출력으로 확인 |
| 부저 | `tone()`을 사용하는 수동(passive) 부저인지 확인. 능동 부저면 소리 높이가 고정됨 |
| 스트립 픽셀 수 | 각 스트립 LED 개수를 세어 `STRIP1_PIXELS`, `STRIP2_PIXELS`에 입력 |
| 외부 전원 | 정격 5V 보조배터리 또는 어댑터 준비. 9V 사각 건전지 직접 연결 금지 |
| 라이브러리 | Arduino IDE에서 `Adafruit NeoPixel` 설치 |
| 안전 | 배선을 바꿀 때 Arduino USB와 외부 전원을 모두 분리 |

제품마다 IR 센서 선 색이 다를 수 있으므로 색상만 보고 연결하지 말고
`VCC`, `GND`, `OUT` 표기를 확인합니다.

---

## 1단계 — 버튼으로 알고리즘 먼저 확인

버튼은 방향이나 특정 센서를 모의하지 않습니다.

- 빨간 버튼(A0): **경고 수동 시작**
- 초록 버튼(A1): **경고 수동 종료**

### 배선

1. 빨간 버튼 한쪽 → A0, 반대쪽 → GND
2. 초록 버튼 한쪽 → A1, 반대쪽 → GND
3. `main.ino`를 업로드하고 시리얼 모니터를 9600 baud로 엽니다.

버튼은 `INPUT_PULLUP`을 사용하므로 별도 풀업 저항이 필요하지 않습니다.
A0·A1은 아두이노 우노에서 디지털 입력으로도 사용할 수 있는 핀입니다.

### 확인 시나리오

| 순서 | 예상 로그 |
|---|---|
| 빨간 버튼 | `상태: 경고 시작 - 빨간 버튼 수동 시작` |
| 경고 중 빨간 버튼 다시 | `경고 유지: 빨간 버튼 재입력` |
| 초록 버튼 | `상태: 대기 복귀 - 초록 버튼 수동 종료` |
| 대기 중 초록 버튼 | 아무 로그도 나오지 않음(정상) |

버튼을 길게 눌러도 시작 또는 종료는 한 번만 처리됩니다.

## 2단계 — 빨간 경고 LED와 부저 연결

### 빨간 경고 LED

운전자에게 보이도록 반투명 표지판 뒤에 빨간 LED 1개 또는 저항이 내장된
빨간 LED 모듈 1개를 배치합니다.

- 일반 LED: D8 → 220~330Ω 저항 → LED 긴 다리(+)
- LED 짧은 다리(−) → GND
- RGB LED를 쓸 경우 빨간색 핀에만 신호를 연결합니다.

일반 LED 여러 개를 D8에 직접 병렬 연결하지 않습니다. 여러 개가 필요하면 각 LED에 저항을
사용하고 트랜지스터 또는 MOSFET 구동 회로를 별도로 설계합니다.

### 부저

- 부저 `+` → D9
- 부저 `−` → GND

### 확인

빨간 버튼을 누르면 빨간 LED와 부저가 약 0.3초(`WARNING_BLINK_MS`) 간격으로
**함께** 점멸해야 합니다. 초록 버튼을 누르면 전체 출력이 꺼집니다.

---

## 3단계 — LED 스트립 연결

스트립은 방향 유도용이 아니라 **경고용**입니다.
경고 상태에서 두 스트립 전체가 빨간색으로 켜지며, 흐르는 애니메이션은 없습니다.

### 스트립 1

1. DIN → D6
2. 데이터선에 330~470Ω 직렬 저항 권장
3. 5V → 외부 5V 전원
4. GND → 외부 전원 GND
5. 외부 전원 GND ↔ Arduino GND 공통 연결
6. `STRIP1_PIXELS`를 실제 개수로 수정

빨간 버튼을 눌러 스트립 1 전체가 빨간색으로 켜지는지 확인합니다.

### 스트립 2

스트립 1이 정상일 때 같은 방식으로 DIN만 D7에 연결하고 `STRIP2_PIXELS`를 수정합니다.

전원이 부족하면 색이 변하거나 Arduino가 재부팅될 수 있습니다. 이때
`STRIP_BRIGHTNESS`를 낮추고 외부 전원 용량을 확인합니다.

## 4단계 — IR 센서 4개 연결

### 진입 감지 IR 2개

- IR 1: `VCC` → 5V, `GND` → GND, `OUT` → **D2**
- IR 2: `VCC` → 5V, `GND` → GND, `OUT` → **D3**

### 통과 감지 IR 2개

- IR 3: `VCC` → 5V, `GND` → GND, `OUT` → **D4**
- IR 4: `VCC` → 5V, `GND` → GND, `OUT` → **D5**

### 설치 위치

```text
   인도(출발 쪽)              차도               인도(도착 쪽)
[진입 IR 1] [진입 IR 2]  [스트립 1·2]   [통과 IR 1] [통과 IR 2]
   보행자가 도로로                       보행자가 다 건너
   내려서는 지점                          올라서는 지점
```

진입 IR은 보행자가 차도로 들어서는 구간을, 통과 IR은 반대편에 도착하는 구간을 감지하도록
설치합니다. 진입 IR과 통과 IR을 서로 너무 가깝게 두면 두 신호가 동시에 감지되어
경고가 시작되지 않을 수 있습니다(모호 입력 보호).

### 확인 순서

1. 아무것도 감지되지 않을 때 시리얼에 아무 로그도 나오지 않는지 확인합니다.
2. 진입 IR 앞에 손을 대면 `상태: 경고 시작 - 진입 IR 감지`가 나와야 합니다.
3. 손을 계속 대고 있어도 로그가 반복되지 않아야 합니다.
4. 통과 IR 앞에 손을 대면 `상태: 대기 복귀 - 통과 IR 감지`가 나와야 합니다.
5. 반대로 동작하면 `IR_ACTIVE_LOW`를 변경합니다.
6. 출력이 불안정하면 `IR_USE_INTERNAL_PULLUP = true`를 유지합니다.
7. 잠깐 스쳐도 발동하면 `IR_CONFIRM_MS`를 늘립니다.

## 5단계 — 전체 시연

1. 대기 상태에서 모든 출력이 꺼져 있는지 확인
2. 진입 IR 감지 → 스트립 2줄 전체 빨간색 + 빨간 LED·부저 점멸
3. 통과 IR 감지 → 모든 출력 종료 후 대기 복귀
4. 진입 IR 2와 통과 IR 2로도 같은 동작이 되는지 확인

### 수동 시연

실제 센서가 현장 조명이나 설치 문제로 작동하지 않으면 빨간 버튼으로 경고를 시작하고
초록 버튼으로 종료하는 수동 시연을 사용합니다.

## 모형 배치 권장안

```text
┌──── 인도(출발 쪽) ────┐                    ┌──── 인도(도착 쪽) ────┐
│ 진입 IR 1  진입 IR 2  │                    │ 통과 IR 1  통과 IR 2  │
└───────────┬───────────┘                    └───────────┬───────────┘
            │               도로                         │
       ═════╪════ LED 스트립 1 ══════════════════════════╪═════
       ═════╪════ LED 스트립 2 ══════════════════════════╪═════
            │                                            │
     [빨간 경고 LED / 표지판]                       [부저]
```

MVP에서는 표지판 1개만 제작해도 되지만, 실제 양방향 도로 적용 시 차량 진행 방향마다
표지판을 각각 설치해야 합니다.
