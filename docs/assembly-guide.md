# 4차시 제작 가이드 — 「멈춰 !」 독립 채널 경고 시스템

프로젝트 설명: **돌발 보행자 감지 및 경고 시스템**

회로를 한 번에 모두 연결하지 않고 **버튼 → 단순 출력 → 스트립 → IR 센서** 순서로 제작합니다.

> **지금은 IR 센서 2개 · 스트립 1줄뿐이고 버튼도 없습니다.** 4단계까지는
> `test/test.ino`(축소판, 채널 1개)로 진행하고, 부품을 채운 뒤 `main.ino`(채널 2개)로
> 바꿔 올립니다.

> **독립 채널입니다.** 이슈 #18 기준으로 채널 1(시작 IR 1·D8 + 끝 IR 1·D10 + 스트립1·D4)과
> 채널 2(시작 IR 2·D9 + 끝 IR 2·D11 + 스트립2·`PIN_STRIP_2`)가 서로 독립적으로 작동합니다.
> 한 채널이 경고 중이어도 다른 채널은 별도로 시작·종료할 수 있습니다.

> ⚠ **IR 센서를 서로 마주보게 두지 마세요.** FC-51 / HW-201 계열은 송신 LED와
> 수신 LED가 한 보드에 같이 붙은 **반사형** 모듈이라, 마주보게 두면 서로의 적외선이
> 상대 수신부에 직접 들어가 계속 감지 상태로 붙습니다. 모든 센서를 보행자가 지나갈
> 쪽을 향해 **같은 방향으로** 두세요. 같은 채널의 시작·끝 IR도 서로 마주보지 않게 둡니다.

핀 배정은 [README 6. 핀 연결표](../README.md#6-핀-연결표)와 `main.ino` 상단 설정값을 기준으로 합니다.

- 상태 전이: [동작 상태 흐름도](images/state-flow.svg)

## 0. 부품 확인

| 항목 | 확인 내용 |
|---|---|
| IR 개수 | 최종 구성은 채널별 시작 1개 + 끝 1개, 총 **4개**. 지금 몇 개가 있는지 먼저 확인 |
| IR 출력 | 감지했을 때 HIGH인지 LOW인지 제품 설명 또는 시리얼 출력으로 확인 |
| 부저 | `tone()`을 사용하는 수동(passive) 부저인지 확인. 능동 부저면 소리 높이가 고정됨 |

| 라이브러리 | Arduino IDE에서 `Adafruit NeoPixel` 설치 |
| 안전 | 배선을 바꿀 때 Arduino USB와 외부 전원을 모두 분리 |

## 1단계 — 버튼으로 알고리즘 먼저 확인

버튼은 특정 채널을 모의하지 않고 **두 채널을 한 번에** 조작합니다.

- 빨간 버튼(A0): **두 채널 수동 시작**
- 초록 버튼(A1): **두 채널 수동 종료**

버튼이 아직 없다면 이 단계를 건너뛰고 2단계로 갑니다. `test/test.ino`의
`USE_BUTTONS`가 `false`라 버튼 핀을 아예 읽지 않으므로 오작동하지 않습니다.
버튼을 달면 `USE_BUTTONS`를 `true`로 바꾸세요.

### 배선

1. 빨간 버튼 한쪽 → A0, 반대쪽 → GND
2. 초록 버튼 한쪽 → A1, 반대쪽 → GND
3. 스케치를 업로드하고 시리얼 모니터를 9600 baud로 엽니다.
   (IR 2개 단계에서는 `test/test.ino`, IR 4개를 채운 뒤에는 `main.ino`)

버튼은 `INPUT_PULLUP`을 사용하므로 별도 풀업 저항이 필요하지 않습니다.
A0·A1은 아두이노 우노에서 디지털 입력으로도 사용할 수 있는 핀입니다.

### 확인 시나리오 (`main.ino` 기준)

| 순서 | 예상 로그 |
|---|---|
| 빨간 버튼 | `채널1 시작 - 빨간 버튼 수동 시작`, `채널2 시작 - 빨간 버튼 수동 시작` |
| 초록 버튼 | `채널1 종료 - 초록 버튼 수동 종료`, `채널2 종료 - 초록 버튼 수동 종료` |
| 대기 중 초록 버튼 | 상태 전환 로그 없음(주기 진단 로그만 계속 나옴) |

축소판(`test/test.ino`)은 버튼이 미연결(`USE_BUTTONS=false`)이라 이 단계에서는
버튼 로그를 확인할 수 없습니다.

상태 전환 로그와 별개로, 0.4초(`IR_LOG_INTERVAL_MS`)마다 아래와 같은 진단 줄이
계속 나옵니다. IR 4개의 원시 핀값과 판정, 채널별 상태, 출력 상태를 담고 있습니다.

```text
E1(D8)=1 없음  E2(D9)=1 없음  X1(D10)=1 없음  X2(D11)=1 없음  CH1=IDLE CH2=IDLE SYSTEM=IDLE S1=OFF S2=NC LED=OFF BUZZER=OFF
```

버튼을 길게 눌러도 시작 또는 종료는 한 번만 처리됩니다.

## 2단계 — 빨간 경고 LED와 부저 연결

### 빨간 경고 LED

운전자에게 보이도록 반투명 표지판 뒤에 빨간 LED 1개 또는 저항이 내장된
빨간 LED 모듈 1개를 배치합니다.

- 일반 LED: D3 → 220~330Ω 저항 → LED 긴 다리(+)
- LED 짧은 다리(−) → GND
- RGB LED를 쓸 경우 빨간색 핀에만 신호를 연결합니다.

일반 LED 여러 개를 D3에 직접 병렬 연결하지 않습니다. 여러 개가 필요하면 각 LED에 저항을
사용하고 트랜지스터 또는 MOSFET 구동 회로를 별도로 설계합니다.

### 부저

- 부저 `+` → D5
- 부저 `−` → GND

경고음은 800Hz↔1800Hz를 오르내리는 사이렌이므로 **수동(passive) 부저**여야 합니다.
능동 부저는 안에 발진 회로가 있어 정해진 한 음만 나고, 사이렌으로 들리지 않습니다.
빨간 LED와 부저는 채널이 아니라 **전체 시스템 공용**이므로 하나 이상의 채널이 활성일
때 동작합니다.

### 확인

빨간 버튼을 누르면(또는 시작 IR을 감지하면) 빨간 LED가 약 0.3초(`WARNING_BLINK_MS`)
간격으로 점멸하고, 부저는 **끊기지 않고** 낮은 음에서 높은 음으로 올라갔다 내려오는
사이렌 소리를 냅니다(상승·하강 각 0.5초 = `SIREN_SWEEP_MS`).
모든 채널이 종료되면 소리와 불이 즉시 함께 꺼집니다.

## 3단계 — LED 스트립 연결

스트립은 최종 **2줄**이며 채널마다 하나씩입니다. 방향 유도용이 아니라 경고용이며,
경고 중인 채널의 스트립이 빨간색으로 점멸합니다. 흐르는 애니메이션은 없습니다.

### 스트립 1 (채널 1)

1. DIN → D4
2. 데이터선에 330~470Ω 직렬 저항 권장
3. 5V → 외부 5V 전원
4. GND → 외부 전원 GND
5. 외부 전원 GND ↔ Arduino GND 공통 연결
6. 스트립의 낱개 LED 개수를 세어 `STRIP_1_PIXELS`가 맞는지 확인 (현재 값 10)

시작 IR 1(D8)을 감지시키거나 빨간 버튼을 눌러 스트립 1이 점멸하는지 확인합니다.
뒷부분 몇 개가 안 켜지면 `STRIP_1_PIXELS`가 실물보다 작은 것입니다.

### 스트립 2 (채널 2, 나중에)

두 번째 스트립이 들어오면 **쓸 핀을 먼저 정하고** `main.ino`의 `PIN_STRIP_2_VALUE`에
그 번호를 적습니다. 비어 있는 핀은 D2, D6, D7, D12, D13, A2~A5입니다.

`PIN_STRIP_2`가 `0`인 동안에는 채널 2의 센서 상태 머신은 그대로 동작하지만 스트립 2
출력만 건너뛰므로, 1줄만 꽂아도 그대로 동작합니다. 배선은 스트립 1과 같은 방식입니다.

전원이 부족하면 색이 변하거나 Arduino가 재부팅될 수 있습니다. 이때
`STRIP_BRIGHTNESS`를 낮추고 외부 전원 용량을 확인합니다.

D0·D1은 시리얼 통신에 쓰이므로 아무것도 연결하지 않습니다.

## 4단계 — IR 센서 연결

### 4-A. 지금(IR 2개) — `test/test.ino` (채널 1개, 축소판)

- 시작 IR: `VCC` → 5V, `GND` → GND, `OUT` → **D8**
- 끝 IR: `VCC` → 5V, `GND` → GND, `OUT` → **D9**

두 센서를 채널 1 구간의 시작·끝에 두고, 시작 IR 앞에 손을 넣으면 경고가 시작되고
끝 IR 앞에 손을 넣으면 꺼지는지 확인합니다.

> 축소판에서 D9는 **끝 센서**입니다. 최종 `main.ino`에서 D9는 채널 2의 **시작
> 센서**로 역할이 바뀌므로, 4-B로 넘어갈 때 배선을 그대로 두면 안 됩니다.

### 4-B. 최종(IR 4개) — `main.ino` (채널 2개)

센서 2개를 더 구하면 다음과 같이 배선합니다.

- 채널 1 시작 IR: `OUT` → **D8** (그대로)
- 채널 1 끝 IR: `OUT` → **D10** (축소판의 D9 배선을 이 핀으로 옮김)
- 채널 2 시작 IR: `OUT` → **D9** (새로 추가, 축소판과 핀 번호는 같지만 역할이 다름)
- 채널 2 끝 IR: `OUT` → **D11** (새로 추가)

모든 모듈은 `VCC` → 5V, `GND` → GND로 공통 연결합니다.
배선을 마친 뒤 `main.ino`를 업로드합니다.

### 설치 위치

모든 센서가 **같은 방향**을 봅니다. 마주보게 두면 서로 간섭합니다.

```text
채널 1                                          채널 2
[IR D8]         [LED 스트립1 D4]        [IR D10]        [IR D9]        [LED 스트립2]        [IR D11]
  ↑                                        ↑                ↑                                  ↑
       시작 IR 감지 → 채널1 경고 시작                             시작 IR 감지 → 채널2 경고 시작
       끝 IR 감지   → 채널1만 종료                                끝 IR 감지   → 채널2만 종료
```

각 채널의 시작·끝 센서는 같은 방향을 보게 두고, 두 채널이 서로 다른 구간을 감지하도록
충분히 떨어뜨립니다. 같은 채널 안에서 시작·끝 센서를 너무 가깝게 두면 두 신호가 동시에
감지되어 그 채널이 시작되지 않을 수 있습니다(모호 입력 보호).

### 확인 순서

0. `test/test.ino`와 `main.ino` 모두 IR 핀값·판정과 채널·시스템 상태를 0.4초마다
   시리얼에 찍습니다. 손을 치웠을 때 둘 다 `없음`이 되도록 모듈 위의 파란 나사를
   먼저 맞춥니다.
1. 아무것도 감지되지 않을 때 상태 변화 로그가 나오지 않는지 확인합니다.
2. 채널 1 시작 IR(D8) 앞에 손을 대면 `채널1 시작 - 시작 IR 1 감지`가 나와야 합니다.
3. 손을 계속 대고 있어도 로그가 반복되지 않아야 합니다.
4. 채널 1 끝 IR(D10) 앞에 손을 대면 `채널1 종료 - 끝 IR 1 감지`가 나옵니다.
4-2. 채널 2 시작 IR(D9)·끝 IR(D11)로도 같은 방식을 확인합니다. 채널 1을 끄지 않고도
   채널 2를 독립적으로 시작·종료할 수 있어야 합니다.
4-3. 경고 중에 **같은 채널의** 시작 센서 앞에서 손을 흔들면 `채널N 유지: 시작 IR N
   재감지`가 나오고 그 채널이 꺼지지 않아야 합니다.
5. 반대로 동작하면 `IR_ACTIVE_LOW`를 변경합니다.
6. 출력이 불안정하면 `IR_USE_INTERNAL_PULLUP`을 `true`로 바꿉니다.
7. 잠깐 스쳐도 발동하면 `IR_CONFIRM_MS`를 늘리고, 빠르게 지나갈 때 안 잡히면 줄입니다.
8. `채널N 입력 무시: 시작·끝 센서 동시 감지`나 `... 끝 센서가 이미 감지 중`만 나오면
   **같은 채널의 두 센서가 서로를 보고 있는 것**입니다. 각자 보행자 쪽을 향하도록
   방향을 돌립니다.

## 5단계 — 전체 시연

1. 대기 상태에서 모든 출력이 꺼져 있는지 확인
2. 채널 1 시작 IR 진입 → 스트립1 점멸 + 빨간 LED 점멸 + 부저 사이렌 → 채널 1 끝 IR 도착 → 채널 1만 종료
3. **채널 2도 동일하게**: 채널 2 시작 IR 진입 → 채널 2 끝 IR 도착 → 채널 2만 종료
4. 두 채널을 동시에 켜 보고, 한 채널만 먼저 종료해도 남은 채널과 공용 경고가 유지되는지 확인
5. 경고 중 같은 채널 시작 IR 재감지로는 꺼지지 않는지 확인

### 수동 시연

실제 센서가 현장 조명이나 설치 문제로 작동하지 않으면 빨간 버튼으로 두 채널을 시작하고
초록 버튼으로 종료하는 수동 시연을 사용합니다.

## 모형 배치 권장안

```text
┌──────── 채널 1 ────────┐                    ┌──────── 채널 2 ────────┐
│  IR D8       IR D10    │                    │  IR D9       IR D11   │
└───────────┬─────────────┘                    └───────────┬───────────┘
            │               도로                            │
       ═════╪════ LED 스트립 1 · D4 (LED 10개) ═════════════╪═════
            │                                               │
       ═════╪════ LED 스트립 2 · 핀 미정 ═══════════════════╪═════
            │                                               │
     [빨간 경고 LED / 표지판]                          [부저]
```

MVP에서는 표지판 1개만 제작해도 되지만, 채널을 추가로 늘릴 경우 구간마다
표지판을 각각 설치해야 합니다.
