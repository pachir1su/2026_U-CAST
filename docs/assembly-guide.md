# 4차시 제작 가이드 — 브레드보드 조립 순서

무단횡단 방지 시스템의 회로를 **한 번에 다 꽂지 말고 4단계로 나누어** 만드는 순서입니다.
단계마다 확인 포인트가 있어서, 문제가 생겼을 때 원인을 바로 앞 단계로 좁힐 수 있습니다.

핀 배정은 [README.md 5. 핀 연결표](../README.md#5-핀-연결표)와 `main.ino` 상단
`[설정 1] 핀 번호` 구역이 기준입니다. 셋 중 하나를 바꾸면 나머지도 함께 바꿔야 합니다.

전체 배선 그림: [브레드보드 배선도](images/breadboard-wiring.svg)
동작 흐름 그림: [상태 흐름도](images/state-flow.svg)

---

## 0. 시작 전 준비물 확인

| 항목 | 확인 내용 |
|---|---|
| 부저 종류 | **수동(passive) 부저**여야 합니다. 코드가 `tone()`으로 음 높이를 지정합니다 |
| 스트립 픽셀 수 | LED 알을 직접 세어서 적어 둡니다 (`STRIP1_PIXELS` / `STRIP2_PIXELS`에 입력) |
| 외부 전원 | 보조배터리(5V) 또는 9V 건전지. 스트립 전용입니다 |
| 라이브러리 | Arduino IDE에서 `Adafruit NeoPixel` 설치 완료 |
| 전원 차단 | **배선을 바꿀 때는 항상 USB와 외부 전원을 모두 뽑습니다** |

---

## 1단계 — 버튼 2개만 연결해서 로직 확인

가장 먼저 하는 이유: 버튼이 되면 코드 전체 흐름이 정상이라는 뜻이고,
이후 문제는 전부 센서 배선·감도 문제로 좁혀집니다.

1. 빨간 버튼: 한쪽 다리 → `D10`, 반대쪽 다리 → `GND`
2. 초록 버튼: 한쪽 다리 → `D11`, 반대쪽 다리 → `GND`
3. `main.ino` 업로드 후 시리얼 모니터(9600 baud)를 엽니다.

> 버튼은 코드에서 `INPUT_PULLUP`을 쓰므로 **저항을 따로 달지 않습니다.**
> 4핀 택트 스위치는 마주 보는 두 다리가 이미 붙어 있으니, 대각선 두 다리를 쓰세요.

**확인 포인트**: 빨간 버튼 → 경고 상태 로그, 초록 버튼 → 대기 복귀 로그.
초록 버튼이 바로 안 먹으면 정상입니다. 경고 시작 후 3초(`WARNING_MIN_MS`) 동안은
종료 신호를 무시합니다.

---

## 2단계 — 부저와 빨간색 LED 연결

배선이 단순해서 코드가 실제로 도는지 가장 빨리 눈·귀로 확인할 수 있습니다.

1. 빨간색 LED: `D8` → 220~330Ω 저항 → LED 긴 다리(+), LED 짧은 다리(−) → `GND`
2. 부저: `+` → `D9`, `−` → `GND`
3. 빨간 버튼을 눌러 경고 상태로 만듭니다.

**확인 포인트**: 부저가 "삐- 쉬고 삐-" 울리고 빨간 LED가 약 0.3초 간격으로 점멸합니다.

- 소리가 안 나면 부저 극성(+/−)과 수동 부저 여부를 확인합니다.
- LED가 안 켜지면 긴 다리/짧은 다리를 바꿔 꽂아 봅니다.

---

## 3단계 — LED 스트립 1개 먼저 연결

**스트립 2개를 한 번에 붙이지 마세요.** 전류 문제와 배선 문제를 구분할 수 없게 됩니다.

1. 스트립 1의 `DIN` → `D6`
2. 스트립 1의 `5V` → **외부 전원 +5V** (아두이노 5V 핀에서 직접 뽑지 않습니다)
3. 스트립 1의 `GND` → 외부 전원 GND **및** 아두이노 `GND`
   → **공통 접지를 빠뜨리면 스트립이 아무 반응이 없거나 제멋대로 켜집니다.**
4. `STRIP1_PIXELS`를 실제 LED 개수로 수정한 뒤 다시 업로드합니다.

**확인 포인트**: 경고 상태에서 밝은 점 하나와 뒤로 어두워지는 꼬리가 한 방향으로 흐릅니다.

- 흐르는 방향이 횡단보도 반대쪽이면 `STRIP1_REVERSE`를 `true`로 바꿉니다.
- 밝기가 불안정하게 깜빡이면 `STRIP_BRIGHTNESS`를 낮춥니다(전류 부족 신호).

여기까지 성공하면 스트립 2를 `D7`에 같은 방식으로 연결하고 `STRIP2_PIXELS`를 채웁니다.

---

## 4단계 — IR 센서 4개 연결

1. 진입 감지 쌍 먼저: IR 1 `OUT` → `D2`, IR 2 `OUT` → `D3`
2. 각 센서의 `VCC` → 아두이노 `5V`, `GND` → 아두이노 `GND`
3. 시리얼 모니터를 열고 손을 센서 앞 **30cm**에 대 봅니다.
4. 정상 동작을 확인한 뒤 통과 감지 쌍(IR 3 → `D4`, IR 4 → `D5`)을 연결합니다.

**확인 포인트**: 손을 대면 경고 상태로 전환, 반대편 센서를 가리면 대기로 복귀.

- 아무것도 없는데 계속 감지되면 `IR_ACTIVE_LOW`를 `false`로 바꿉니다.
- 감지 거리는 코드보다 **센서 뒷면 파란색 가변저항**을 먼저 돌려서 맞춥니다.

## 설치 배치 (모형 기준)

```
   인도                차도                  인도
 ┌────────┐  ┌──────────────────┐  ┌────────┐
 │ IR1 IR2│  │ 스트립1  스트립2 │  │ IR3 IR4│
 │  D2 D3 │  │   D6      D7     │  │  D4 D5 │
 └────────┘  └──────────────────┘  └────────┘
   진입 감지      운전자 경고           통과 감지
```

- 진입 IR 쌍은 **연석(차도 경계선)을 향하게** 설치합니다.
- 통과 IR 쌍은 반대편 인도 위, 다 건넌 뒤에만 지나가는 위치에 둡니다.
- 두 쌍이 서로의 감지 범위에 겹치지 않도록 충분히 떨어뜨립니다.

## 제작 후 기록할 것

| 항목 | 내용 |
|---|---|
| 스트립 실제 픽셀 수 | `STRIP1_PIXELS` / `STRIP2_PIXELS`에 입력한 값 |
| 최종 조정값 | `IR_ACTIVE_LOW`, `ENTRY_CONFIRM_MS`, `STRIP_BRIGHTNESS` 등 바꾼 값 |
| 촬영 | 외관 / 회로 / 대기 상태 / **경고 작동 영상** / 종결 영상 |
| 문제 기록 | 잘 안 된 부분과 해결 방법 → [문제 해결 가이드](troubleshooting.md)에 반영 |

> 경고 작동 영상은 **어두운 곳에서 촬영**해야 스트립이 흐르는 장면이 잘 보입니다.
