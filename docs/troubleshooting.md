# 문제 해결 가이드

실물 제작 중 자주 발생하는 증상과 확인 순서입니다.
먼저 버튼으로 알고리즘이 정상인지 확인한 뒤 센서와 출력 배선을 점검합니다.

조정값은 [README 7. 코드 구조](../README.md#7-코드-구조)와 `main.ino` 상단 설정 구역에 있습니다.

---

## 업로드 단계

| 증상 | 확인 순서 |
|---|---|
| `Adafruit_NeoPixel.h: No such file` | Arduino IDE 라이브러리 관리에서 `Adafruit NeoPixel` 설치 |
| 포트가 안 보임 | 데이터 전송 가능한 USB 케이블인지 확인하고 보드를 `Arduino Uno`로 선택 |
| 업로드 실패 | D0·D1에 부품을 연결하지 않았는지 확인 |
| 시리얼 문자가 깨짐 | 시리얼 모니터를 9600 baud로 설정 |

---

## 전체가 반응하지 않을 때

1. 전원을 켰을 때 시리얼 모니터에 `무단횡단 방지 시스템 시작 - 대기 상태` 로그가 나오는지 확인합니다.
2. 빨간 버튼을 눌러 경고가 시작되는지 확인합니다.
3. 초록 버튼을 눌러 경고가 종료되는지 확인합니다.
4. 버튼으로 정상이라면 코드의 상태 전이는 정상이고, 실제 IR 센서 또는 배선 문제입니다.
5. 버튼도 안 되면 4핀 택트 스위치의 연결 다리를 확인합니다. 같은 쪽 두 다리는 내부에서 연결된 제품이 많습니다.
6. PC에서 `bash tests/run-tests.sh`를 실행하면 코드 로직만 따로 검증할 수 있습니다.

## IR 센서

### 기본 확인

최종 구성(`main.ino`)은 왼쪽 연석 2개(D8·D9)와 오른쪽 연석 2개(D10·D11), 총 4개를
각각 다른 핀에 연결합니다. **양방향**이라 어느 쪽이 출발이든 상관없습니다.

지금처럼 IR이 2개뿐일 때는 축소판 스케치(`test/test.ino`)를 쓰며,
**왼쪽 → D8, 오른쪽 → D10** 한 개씩만 연결합니다. D9·D11은 비워 둡니다.

### 가장 흔한 실수 — 센서를 마주보게 둠

이 프로젝트가 쓰는 FC-51 / HW-201 계열은 송신 LED(투명)와 수신 LED(검정)가 한 보드에
같이 붙은 **반사형 장애물 감지** 모듈입니다. 빔이 끊기는 것을 보는 송수신 분리형이
**아닙니다.**

마주보게 두면 한쪽 송신 LED가 반대쪽 수신부에 직접 꽂혀 손이 없어도 계속 감지
상태가 됩니다. 그러면 시리얼에 `입력 무시: 진입과 통과가 동시에 감지됨`만 반복되고
경고가 시작되지 않습니다.

```text
올바름:  도로 양쪽 연석에 두고, 각자 보행자가 지나갈 쪽을 향하게 설치
잘못됨:  두 센서를 도로 건너 서로 마주보게 설치 → 서로 간섭
```

`main.ino`와 `test/test.ino` 모두 IR 핀값과 판정을 0.4초(`IR_LOG_INTERVAL_MS`)마다
시리얼에 찍습니다. 손을 치웠는데도 `감지`가 유지되면 배치나 감도 나사부터 확인하세요.

| 증상 | 가능한 원인 | 조치 |
|---|---|---|
| 아무것도 없는데 계속 감지 | 출력 논리가 반대이거나 감지 거리 조정 필요 | `IR_ACTIVE_LOW`를 `false`로 변경하거나 모듈의 감도 조절 나사를 조정 |
| 손을 대도 값이 안 변함 | 감지 거리 밖이거나 OUT 미연결 | 거리를 줄이고 `OUT` 배선을 확인 |
| 출력값이 떠다님 | 풀업 부족 | `IR_USE_INTERNAL_PULLUP`을 `true`로 변경, `GND` 공통 연결 확인 |
| 검은 물체만 감지 안 됨 | 반사형 모듈 특성 | 검은색·광택 표면은 적외선을 잘 되돌리지 않음. 손이나 밝은 물체로 시연 |
| 잠깐 스쳐도 발동 | 신호 확정 시간이 짧음 | `IR_CONFIRM_MS`를 80 → 150~250으로 증가 |
| 반응이 너무 느림 | 확정 시간이 김 | `IR_CONFIRM_MS`를 80 → 40~60으로 감소 |
| 실내에서는 되는데 현장에서 불안정 | 직사광선·강한 조명 간섭 | 센서에 차광 덮개를 만들고 감지 거리를 줄임 |
| 한쪽 연석 센서가 반응 없음 | OUT 핀 오배선 | `main.ino`는 D8·D9=왼쪽 / D10·D11=오른쪽, `test/test.ino`는 D8=왼쪽 / D10=오른쪽 |

### 센서 위치 오류

양쪽 연석 센서를 서로 가깝게 두면 한 번의 통과로 두 신호가 동시에 잡혀
경고가 시작되지 않습니다.

```text
올바름: [왼쪽 IR] ──── 도로 ──── [오른쪽 IR]
잘못됨: [왼쪽 IR][오른쪽 IR] ──── 도로 ────
```

### 경고가 시작되지 않을 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 가려도 시작 안 됨, 로그에 `입력 무시: 양쪽이 동시에 감지됨` | 반대쪽도 동시에 감지 중 | 반대쪽 앞을 가리는 물체를 치우고, 센서가 서로를 보지 않도록 방향을 돌림 |
| 로그에 `입력 무시: 오른쪽이 계속 감지 중` (또는 왼쪽) | 그쪽 센서가 계속 붙어 있음 | 감도 나사로 감지 거리를 줄이고 앞의 장애물을 치움 |
| 계속 가려도 다시 시작 안 됨 | 감지 유지 상태에서는 이벤트가 반복되지 않음 | 정상 동작. 손을 뗀 뒤 다시 가려야 새 이벤트가 발생 |

### 양방향이 한쪽만 동작할 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 왼→오는 되는데 오→왼이 안 됨 | 오른쪽 연석 센서 배선·감도 문제 | 시리얼 진단 줄의 `D10=` 핀값과 판정을 보며 손을 대 봄 |
| 출발한 쪽에서 손을 흔들면 경고가 꺼짐 | 양방향 로직이 아닌 옛 코드 | 최신 `main.ino` / `test/test.ino`를 올렸는지 확인. 정상이면 `경고 유지: 출발한 쪽 재감지` 로그가 나옴 |
| 건너자마자 바로 다시 경고가 켜짐 | 도착 쪽 센서 앞에 계속 서 있음 | 정상 동작. 도착 후 센서 앞에서 비켜야 함 |

## 버튼

| 증상 | 원인 | 조치 |
|---|---|---|
| 버튼이 아예 반응 없음 | `USE_BUTTONS = false` | `test/test.ino`는 버튼 미연결이 기본입니다. 버튼을 달았으면 `true`로 변경 |
| 빨간 버튼을 눌러도 경고가 안 켜짐 | A0 배선 또는 GND 미연결 | 빨간 버튼 A0 ↔ GND 연결 확인 |
| 초록 버튼을 눌러도 종료 안 됨 | A1 배선 오류 | 초록 버튼 A1 ↔ GND 연결 확인 |
| 대기 중 초록 버튼이 아무 반응 없음 | 초록 버튼은 종료 전용 | 정상 동작 |
| 경고 중 빨간 버튼이 아무 반응 없음 | 빨간 버튼은 시작 전용 | 정상 동작 |
| 버튼을 길게 눌러도 한 번만 반응 | 엣지 처리 | 정상 동작 |
| 한 번 눌렀는데 여러 번 반응 | 채터링 | `BUTTON_DEBOUNCE_MS` 증가 |

버튼 옆에 `경고 시작`, `경고 종료` 라벨을 붙이면 혼동을 줄일 수 있습니다.

## LED 스트립

| 증상 | 원인 | 조치 |
|---|---|---|
| 전혀 안 켜짐 | 공통 접지 누락 | 외부 전원 GND와 Arduino GND 연결 |
| 일부만 켜짐 | 픽셀 수 불일치 | `STRIP_1_PIXELS` / `STRIP_2_PIXELS`를 실제 LED 개수로 수정 (현재 10) |
| 두 번째 스트립이 안 켜짐 | `PIN_STRIP_2`가 0 | 쓸 핀 번호를 `PIN_STRIP_2`에 적어야 두 번째 스트립이 동작합니다 |
| 색이 빨강이 아님 | 스트립 색상 순서 차이 | `WARN_COLOR_R/G/B` 조합 조정 |
| 밝기가 흔들리거나 보드 재부팅 | 전원 부족 | 외부 5V 전원 사용, 밝기 감소 |
| 아예 반응 없음 | DIN 핀 오류 | 스트립 1 `DIN`이 **D4**에, 스트립 2가 `PIN_STRIP_2`에 적은 핀에 연결됐는지 확인 |
| 흐르는 애니메이션이 안 나옴 | 현재 설계 오해 | 최종 기획은 방향 애니메이션 없이 전체 빨간색 점등이므로 정상 |
| 스트립이 점멸하지 않음 | 설계 확인 | 정상. 점멸하는 것은 빨간 경고 LED와 부저이며 스트립은 계속 켜져 있음 |

네오픽셀 전원에 일반 9V 사각 건전지를 직접 연결하지 않습니다.

## 빨간 경고 LED

| 증상 | 원인 | 조치 |
|---|---|---|
| LED가 안 켜짐 | 극성 반대 | 긴 다리(+)와 짧은 다리(−) 확인 |
| LED가 매우 어두움 | 표지판 재질이 불투명하거나 저항이 너무 큼 | 반투명 재질 사용, 220~330Ω 범위 확인 |
| LED가 뜨거움 | 저항 누락 | 즉시 전원 분리 후 저항 추가 |
| 여러 LED를 달자 D3이 불안정 | 핀 허용 전류 초과 | 직접 병렬 연결 중단, 트랜지스터/MOSFET 구동 사용 |
| 점멸이 너무 빠르거나 느림 | 간격 설정 | `WARNING_BLINK_MS` 조정 |

## 부저

| 증상 | 원인 | 조치 |
|---|---|---|
| 소리가 안 남 | 능동/수동 부저 혼동 또는 극성 오류 | 수동 부저인지 확인하고 + D5, − GND 연결 |
| 음 높이가 안 변하고 한 음만 남 | 능동(active) 부저를 사용 중 | `tone()`으로 음이 바뀌는 수동(passive) 부저로 교체 |
| 사이렌 폭이 너무 넓거나 좁음 | 주파수 범위 설정 | `SIREN_MIN_HZ`·`SIREN_MAX_HZ` 조정 |
| 사이렌이 너무 느리거나 빠름 | 구간 길이 설정 | `SIREN_SWEEP_MS` 조정(기본 500ms) |
| 소리가 계단처럼 끊겨 들림 | 갱신 간격이 너무 큼 | `SIREN_UPDATE_MS`를 20~30ms 범위에서 줄임 |
| 빨간 LED가 꺼질 때 소리도 끊김 | 옛 코드 사용 | 최신 스케치에서는 LED만 점멸하고 부저는 계속 울립니다 |
| 종료했는데 소리가 남음 | 옛 코드 사용 | 최신 스케치는 종료 즉시 `noTone()`을 호출합니다 |
| 네오픽셀 갱신 때 소리가 미세하게 흔들림 | 네오픽셀 전송 특성 | 일반적인 현상이며 시연에 큰 영향 없음 |

## 상태 전환

| 증상 | 원인 | 조치 |
|---|---|---|
| 경고가 계속 유지됨 | 반대편 도착 미감지 | 초록 버튼으로 종료 시험 후 반대편 센서 설치 위치 확인 |
| 경고가 저절로 꺼짐 | `WARNING_TIMEOUT_MS`가 0보다 큼 | `test/test.ino`는 버튼이 없어 10초 자동 복귀가 **기본 켜짐**입니다. 끄려면 0으로 변경 (`main.ino`는 기본 0) |
| 출발한 쪽을 다시 지나도 아무 변화 없음 | 이미 경고 상태 | 정상. 출발 쪽 재감지는 상태를 유지만 함 |
| 켜졌다가 바로 꺼짐 | 양쪽이 거의 동시에 감지 | 두 센서를 도로 폭만큼 충분히 떨어뜨리고 서로를 보지 않게 배치 |

## 발표 당일 비상 대응

| 상황 | 대응 |
|---|---|
| IR 감지 실패 | 빨간 버튼으로 시작, 초록 버튼으로 종료하는 수동 시연 (버튼 필요) |
| 두 센서가 서로 간섭 | 각자 보행자 쪽을 향하게 돌리고 간격을 벌림. 급하면 `IR_AMBIGUITY_GUARD = false` |
| 밝은 조명으로 IR 불안정 | 센서에 검은 종이 차광 덮개 설치 |
| 스트립 전원 부족 | `STRIP_BRIGHTNESS`를 낮추고 외부 5V 전원 재확인 |
| 빨간 경고 LED 고장 | 스트립과 부저 중심으로 시연하고 예비 LED로 교체 |
| 전체 회로 고장 | 미리 촬영한 진입 감지·통과 감지 시연 영상 사용 |

발표 전에 센서 자동 시연과 버튼 수동 시연을 각각 영상으로 촬영해 둡니다.
