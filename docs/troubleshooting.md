# 문제 해결 가이드

실물 제작 중 자주 발생하는 증상과 확인 순서입니다.
먼저 버튼으로 알고리즘이 정상인지 확인한 뒤 센서와 출력 배선을 점검합니다.

조정값은 [README 7. 코드 구조](../README.md#7-코드-구조)와 `main.ino` 상단 설정 구역에 있습니다.

---

## 업로드 단계

| 증상 | 확인 순서 |
|---|---|
| `Adafruit_NeoPixel.h: No such file` | Arduino IDE 라이브러리 관리에서 `Adafruit NeoPixel` 설치 |
| 포트가 안 보임 | 데이터 전송 가능한 USB 케이블인지 확인하고 보드를 `Arduino Uno`로 선택 |
| 업로드 실패 | D0·D1에 부품을 연결하지 않았는지 확인 |
| 시리얼 문자가 깨짐 | 시리얼 모니터를 9600 baud로 설정 |

---

## 전체가 반응하지 않을 때

1. 전원을 켰을 때 시리얼 모니터에 `무단횡단 방지 시스템 시작 - 대기 상태` 로그가 나오는지 확인합니다.
2. 빨간 버튼을 눌러 경고가 시작되는지 확인합니다.
3. 초록 버튼을 눌러 경고가 종료되는지 확인합니다.
4. 버튼으로 정상이라면 코드의 상태 전이는 정상이고, 실제 IR 센서 또는 배선 문제입니다.
5. 버튼도 안 되면 4핀 택트 스위치의 연결 다리를 확인합니다. 같은 쪽 두 다리는 내부에서 연결된 제품이 많습니다.
6. PC에서 `bash tests/run-tests.sh`를 실행하면 코드 로직만 따로 검증할 수 있습니다.

## IR 센서

### 기본 확인

최종 구성(`main.ino`)은 진입 감지 2개(D2·D3)와 통과 감지 2개(D4·D5), 총 4개를
각각 다른 핀에 연결합니다.

지금처럼 IR이 2개뿐일 때는 축소판 스케치(`test/test.ino`)를 쓰며,
**진입 IR → D2, 통과 IR → D3** 한 개씩만 연결합니다. 이때 D4·D5는 비워 둡니다.

| 증상 | 가능한 원인 | 조치 |
|---|---|---|
| 아무것도 없는데 계속 감지 | 출력 논리가 반대이거나 감지 거리 조정 필요 | `IR_ACTIVE_LOW`를 `false`로 변경하거나 모듈의 감도 조절 나사를 조정 |
| 손을 대도 값이 안 변함 | 감지 거리 밖이거나 OUT 미연결 | 거리를 줄이고 `OUT` 배선을 확인 |
| 출력값이 떠다님 | 오픈 컬렉터 출력 | `IR_USE_INTERNAL_PULLUP = true` 유지, `GND` 공통 연결 확인 |
| 잠깐 스쳐도 발동 | 신호 확정 시간이 짧음 | `IR_CONFIRM_MS`를 80 → 150~250으로 증가 |
| 반응이 너무 느림 | 확정 시간이 김 | `IR_CONFIRM_MS`를 80 → 40~60으로 감소 |
| 실내에서는 되는데 현장에서 불안정 | 직사광선·강한 조명 간섭 | 센서에 차광 덮개를 만들고 감지 거리를 줄임 |
| 진입과 통과가 반대로 동작 | OUT 핀을 바꿔 연결 | `main.ino`는 D2·D3=진입 / D4·D5=통과, `test/test.ino`는 D2=진입 / D3=통과 |

### 센서 위치 오류

진입 IR과 통과 IR을 서로 가깝게 두면 한 번의 통과로 두 신호가 동시에 잡혀
경고가 시작되지 않습니다.

```text
올바름: [진입 IR] ──── 도로 ──── [통과 IR]
잘못됨: [진입 IR][통과 IR] ──── 도로 ────
```

### 경고가 시작되지 않을 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 진입 IR을 가려도 시작 안 됨, 로그에 `입력 무시: 진입과 통과가 동시에 감지됨` | 통과 IR도 동시에 감지 중 | 통과 IR 앞을 가리는 물체를 치우고 두 센서 사이 거리를 늘림 |
| 진입 IR을 계속 가려도 다시 시작 안 됨 | 감지 유지 상태에서는 이벤트가 반복되지 않음 | 정상 동작. 손을 뗀 뒤 다시 가려야 새 이벤트가 발생 |
| 대기 중 통과 IR을 가려도 아무 일 없음 | 통과 IR은 종료 조건 전용 | 정상 동작 |

## 버튼

| 증상 | 원인 | 조치 |
|---|---|---|
| 빨간 버튼을 눌러도 경고가 안 켜짐 | A0 배선 또는 GND 미연결 | 빨간 버튼 A0 ↔ GND 연결 확인 |
| 초록 버튼을 눌러도 종료 안 됨 | A1 배선 오류 | 초록 버튼 A1 ↔ GND 연결 확인 |
| 대기 중 초록 버튼이 아무 반응 없음 | 초록 버튼은 종료 전용 | 정상 동작 |
| 경고 중 빨간 버튼이 아무 반응 없음 | 빨간 버튼은 시작 전용 | 정상 동작 |
| 버튼을 길게 눌러도 한 번만 반응 | 엣지 처리 | 정상 동작 |
| 한 번 눌렀는데 여러 번 반응 | 채터링 | `BUTTON_DEBOUNCE_MS` 증가 |

버튼 옆에 `경고 시작`, `경고 종료` 라벨을 붙이면 혼동을 줄일 수 있습니다.

## LED 스트립

| 증상 | 원인 | 조치 |
|---|---|---|
| 전혀 안 켜짐 | 공통 접지 누락 | 외부 전원 GND와 Arduino GND 연결 |
| 일부만 켜짐 | 픽셀 수 불일치 | `STRIP_PIXELS`를 실제 LED 개수로 수정 (현재 값 10) |
| 색이 빨강이 아님 | 스트립 색상 순서 차이 | `WARN_COLOR_R/G/B` 조합 조정 |
| 밝기가 흔들리거나 보드 재부팅 | 전원 부족 | 외부 5V 전원 사용, 밝기 감소 |
| 아예 반응 없음 | DIN 핀 오류 | 스트립 `DIN`이 **D6**에 연결됐는지 확인 (D7은 사용하지 않음) |
| 흐르는 애니메이션이 안 나옴 | 현재 설계 오해 | 최종 기획은 방향 애니메이션 없이 전체 빨간색 점등이므로 정상 |
| 스트립이 점멸하지 않음 | 설계 확인 | 정상. 점멸하는 것은 빨간 경고 LED와 부저이며 스트립은 계속 켜져 있음 |

네오픽셀 전원에 일반 9V 사각 건전지를 직접 연결하지 않습니다.

## 빨간 경고 LED

| 증상 | 원인 | 조치 |
|---|---|---|
| LED가 안 켜짐 | 극성 반대 | 긴 다리(+)와 짧은 다리(−) 확인 |
| LED가 매우 어두움 | 표지판 재질이 불투명하거나 저항이 너무 큼 | 반투명 재질 사용, 220~330Ω 범위 확인 |
| LED가 뜨거움 | 저항 누락 | 즉시 전원 분리 후 저항 추가 |
| 여러 LED를 달자 D8이 불안정 | 핀 허용 전류 초과 | 직접 병렬 연결 중단, 트랜지스터/MOSFET 구동 사용 |
| 점멸이 너무 빠르거나 느림 | 간격 설정 | `WARNING_BLINK_MS` 조정 |

## 부저

| 증상 | 원인 | 조치 |
|---|---|---|
| 소리가 안 남 | 능동/수동 부저 혼동 또는 극성 오류 | 수동 부저인지 확인하고 + D9, − GND 연결 |
| 음이 너무 높거나 낮음 | 주파수 설정 | `BUZZER_FREQUENCY_HZ` 조정 |
| 계속 울리지 않고 끊어짐 | 빨간 LED와 함께 점멸하는 설계 | 정상. `WARNING_BLINK_MS`로 조정 |
| 빨간 LED와 소리 타이밍이 다름 | 다른 코드 사용 | 현재 `main.ino`는 같은 점멸 상태를 공유하므로 D8·D9 배선 확인 |
| 네오픽셀 갱신 때 소리가 미세하게 흔들림 | 네오픽셀 전송 특성 | 일반적인 현상이며 시연에 큰 영향 없음 |

## 상태 전환

| 증상 | 원인 | 조치 |
|---|---|---|
| 경고가 계속 유지됨 | 통과 IR 미감지 | 초록 버튼으로 종료 시험 후 통과 IR 설치 위치 확인 |
| 경고가 저절로 꺼짐 | `WARNING_TIMEOUT_MS`가 0보다 큼 | 자동 종료는 선택 기능입니다. 기본값 0으로 되돌리면 자동 종료하지 않습니다 |
| 진입 IR을 다시 지나도 경고가 다시 시작되지 않음 | 이미 경고 상태 | 정상. 경고 중 진입 입력은 상태를 유지만 함 |
| 켜졌다가 바로 꺼짐 | 진입 IR과 통과 IR이 거의 동시에 감지 | 두 센서 사이 거리를 늘리고 설치 위치를 분리 |

## 발표 당일 비상 대응

| 상황 | 대응 |
|---|---|
| IR 감지 실패 | 빨간 버튼으로 시작, 초록 버튼으로 종료하는 수동 시연 |
| 밝은 조명으로 IR 불안정 | 센서에 검은 종이 차광 덮개 설치 |
| 스트립 전원 부족 | `STRIP_BRIGHTNESS`를 낮추고 외부 5V 전원 재확인 |
| 빨간 경고 LED 고장 | 스트립과 부저 중심으로 시연하고 예비 LED로 교체 |
| 전체 회로 고장 | 미리 촬영한 진입 감지·통과 감지 시연 영상 사용 |

발표 전에 센서 자동 시연과 버튼 수동 시연을 각각 영상으로 촬영해 둡니다.
