# 문제 해결 가이드

실물 제작 중 자주 발생하는 증상과 확인 순서입니다.
먼저 버튼으로 알고리즘이 정상인지 확인한 뒤 센서와 출력 배선을 점검합니다.

조정값은 [README 7. 코드 구조](../README.md#7-코드-구조)와 `main.ino` 상단 설정 구역에 있습니다.

---

## 업로드 단계

| 증상 | 확인 순서 |
|---|---|
| `Adafruit_NeoPixel.h: No such file` | Arduino IDE 라이브러리 관리에서 `Adafruit NeoPixel` 설치 |
| 포트가 안 보임 | 데이터 전송 가능한 USB 케이블인지 확인하고 보드를 `Arduino Uno`로 선택 |
| 업로드 실패 | D0·D1에 부품을 연결하지 않았는지 확인 |
| 시리얼 문자가 깨짐 | 시리얼 모니터를 9600 baud로 설정 |

---

## 전체가 반응하지 않을 때

1. 전원을 켰을 때 시리얼 모니터에 `양방향 대기` 로그가 나오는지 확인합니다.
2. 빨간 버튼을 누른 뒤 0.8초 이상 기다리고 초록 버튼을 누릅니다.
3. 반대 순서도 시험합니다.
4. 버튼으로 정상이라면 코드의 상태 전이는 정상이고, 실제 IR 센서 또는 배선 문제입니다.
5. 버튼도 안 되면 4핀 택트 스위치의 연결 다리를 확인합니다. 같은 쪽 두 다리는 내부에서 연결된 제품이 많습니다.

## IR 브레이크빔 센서

### 기본 확인

IR 브레이크빔 1세트는 송신부와 수신부가 서로 마주 봐야 합니다.
반사형 장애물 센서처럼 한 모듈을 사람 쪽으로 향하게 사용하는 구조가 아닙니다.

| 증상 | 가능한 원인 | 조치 |
|---|---|---|
| 빔을 안 가렸는데 계속 감지 | 출력 논리가 반대 | `IR_ACTIVE_LOW`를 `false`로 변경 |
| 빔을 가려도 값이 안 변함 | 송수신부 정렬 불량 | 높이와 각도를 다시 맞추고 거리를 줄여 시험 |
| 수신부 값이 떠다님 | 오픈 컬렉터 출력 또는 OUT 미연결 | `IR_USE_INTERNAL_PULLUP = true`, OUT·GND 확인 |
| 잠깐 흔들려도 발동 | 신호 확정 시간이 짧음 | `IR_CONFIRM_MS`를 80 → 150~250으로 증가 |
| 반응이 너무 느림 | 확정 시간이 김 | `IR_CONFIRM_MS`를 80 → 40~60으로 감소 |
| 실내에서는 되는데 현장에서 불안정 | 직사광선·강한 조명 간섭 | 수신부에 차광 덮개를 만들고 송수신 거리를 줄임 |
| 왼쪽과 오른쪽이 반대로 표시 | OUT 핀을 바꿔 연결 | D2는 왼쪽, D3은 오른쪽인지 확인 |

### 센서 위치 오류

센서는 도로 위 자동차를 감지하도록 도로를 가로질러 설치하지 않습니다.
각 세트는 **한쪽 인도에서 사람이 차도로 내려가는 통과 구간**을 가로질러 설치합니다.

```text
올바름: 송신부 ●──── 보행자 통과 구간 ────● 수신부
잘못됨: 왼쪽 인도 ●──────── 도로 전체 ────────● 오른쪽 인도
```

### 방향 판정이 이상할 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 왼쪽 시작 후 오른쪽에서 끝나지 않음 | 오른쪽 센서가 새 차단 이벤트를 만들지 못함 | 오른쪽 빔이 시작 전에 정상 상태였는지 확인하고 다시 정렬 |
| 출발 직후 바로 종료됨 | 반대편 빔도 동시에 흔들림 | 센서 전원·정렬 확인, `CROSSING_MIN_MS` 증가 |
| 양쪽이 동시에 작동해 아무 일도 안 일어남 | 방향 판정 불가 보호 로직 | 한쪽 빔을 먼저 통과하도록 시연하고 센서 간 간섭 확인 |
| 여러 사람이 반대 방향으로 동시에 들어옴 | 2세트 구조의 한계 | MVP에서는 한 번에 한 방향만 시연. 실제 확장 시 감지선 추가 검토 |

## 버튼

| 증상 | 원인 | 조치 |
|---|---|---|
| 빨간 버튼이 경고를 끔 | 버튼 의미 오해 | 빨간색은 왼쪽 IR, 초록색은 오른쪽 IR 모의 입력임 |
| 초록 버튼을 눌러도 종료 안 됨 | 현재 방향이 오른쪽→왼쪽이거나 최소 시간이 지나지 않음 | 상태 로그 확인. 왼→오 횡단 중에만 초록 버튼이 도착 입력임 |
| 같은 버튼을 다시 눌러도 반응 없음 | 출발지 반복 입력 무시 | 정상 동작 |
| 한 번 눌렀는데 여러 번 반응 | 채터링 | `BUTTON_DEBOUNCE_MS` 증가 |

버튼 옆에 `왼쪽 IR`, `오른쪽 IR` 라벨을 붙이면 색상으로 인한 혼동을 줄일 수 있습니다.

## 차도 네오픽셀 스트립

| 증상 | 원인 | 조치 |
|---|---|---|
| 전혀 안 켜짐 | 공통 접지 누락 | 외부 전원 GND와 Arduino GND 연결 |
| 일부만 켜짐 | 픽셀 수 불일치 | `STRIP1_PIXELS`, `STRIP2_PIXELS`를 실제 개수로 수정 |
| 색이 빨강이 아님 | 스트립 색상 순서 차이 | `WARN_COLOR_R/G/B` 조합 조정 |
| 밝기가 흔들리거나 보드 재부팅 | 전원 부족 | 외부 5V 전원 사용, 밝기 감소 |
| 한 스트립만 켜짐 | DIN 또는 핀 오류 | 스트립 1 D6, 스트립 2 D7 확인 |
| 흐르는 애니메이션이 안 나옴 | 현재 설계 오해 | 최종 기획은 방향 유도가 아니라 전체 빨간색 점멸이므로 정상 |
| 점멸이 너무 빠르거나 느림 | 간격 설정 | `WARNING_LIGHT_BLINK_MS` 조정 |

네오픽셀 전원에 일반 9V 사각 건전지를 직접 연결하지 않습니다.

## `보행자 주의` 표지판 LED

| 증상 | 원인 | 조치 |
|---|---|---|
| LED가 안 켜짐 | 극성 반대 | 긴 다리(+)와 짧은 다리(−) 확인 |
| LED가 매우 어두움 | 표지판 재질이 불투명하거나 저항이 너무 큼 | 반투명 재질 사용, 220~330Ω 범위 확인 |
| LED가 뜨거움 | 저항 누락 | 즉시 전원 분리 후 저항 추가 |
| 여러 LED를 달자 D8이 불안정 | 핀 허용 전류 초과 | 직접 병렬 연결 중단, 트랜지스터/MOSFET 구동 사용 |
| 표지판과 스트립 점멸이 어긋남 | 배선 또는 다른 코드 사용 | 현재 `main.ino`는 같은 점멸 상태를 공유하므로 D8·D6·D7 확인 |

## 부저

| 증상 | 원인 | 조치 |
|---|---|---|
| 소리가 안 남 | 능동/수동 부저 혼동 또는 극성 오류 | 수동 부저인지 확인하고 + D9, − GND 연결 |
| 음이 너무 높거나 낮음 | 주파수 설정 | `BUZZER_FREQ_HZ` 조정 |
| 계속 울리지 않고 끊어짐 | 간헐 경고 설계 | 정상. `BUZZER_ON_MS`, `BUZZER_OFF_MS`로 조정 |
| 네오픽셀 갱신 때 소리가 미세하게 흔들림 | 네오픽셀 전송 특성 | 일반적인 현상이며 시연에 큰 영향 없음 |

## 상태 전환과 자동 복귀

| 증상 | 원인 | 조치 |
|---|---|---|
| 반대편에 도착했는데 즉시 안 꺼짐 | 최소 횡단 시간 | `CROSSING_MIN_MS`가 지난 뒤 감지해야 함 |
| 경고가 계속 유지됨 | 반대편 빔 미감지 | 반대편 버튼으로 종료 시험, 센서 정렬 확인 |
| 60초 뒤 저절로 꺼짐 | 안전 자동 복귀 | 정상. 필요하면 `CROSSING_TIMEOUT_MS` 조정 또는 0으로 설정 |
| 출발지 센서를 다시 지나도 종료 안 됨 | 반복 입력 무시 | 정상. 종료는 반대편 센서만 처리 |

## 발표 당일 비상 대응

| 상황 | 대응 |
|---|---|
| IR 정렬 실패 | 빨간·초록 버튼으로 왼쪽·오른쪽 센서 이벤트 모의 |
| 밝은 조명으로 IR 불안정 | 수신부에 검은 종이 차광 덮개 설치 |
| 스트립 전원 부족 | `STRIP_BRIGHTNESS`를 낮추고 외부 5V 전원 재확인 |
| 표지판 LED 고장 | 스트립과 부저 중심으로 시연하고 예비 LED로 교체 |
| 전체 회로 고장 | 미리 촬영한 왼→오, 오→왼 시연 영상 사용 |

발표 전에 센서 자동 시연과 버튼 비상 시연을 각각 영상으로 촬영해 둡니다.
