# 문제 해결 가이드

실물 제작 중 자주 나오는 증상과 확인 순서입니다.
**코드를 고치기 전에 배선과 부품을 먼저 확인하세요.** 대부분은 배선 문제입니다.

조정값 상수의 의미는 [README.md 7. 기준값 조정 가이드](../README.md#7-기준값-조정-가이드)에 있습니다.

---

## 업로드 단계

| 증상 | 확인 순서 |
|---|---|
| `Adafruit_NeoPixel.h: No such file` | 스케치 → 라이브러리 포함하기 → 라이브러리 관리에서 `Adafruit NeoPixel` 설치 |
| 포트가 안 보임 | USB 케이블이 **충전 전용**인지 확인(데이터 케이블 필요), 툴 → 보드에서 `Arduino Uno` 선택 |
| 업로드 중 멈춤 | `D0`, `D1`에 아무것도 꽂혀 있지 않은지 확인 (시리얼 통신 핀) |
| 시리얼 모니터가 깨짐 | 우측 아래 속도를 **9600 baud**로 맞춤 |

---

## 아무 반응이 없을 때

1. 시리얼 모니터(9600)에 시작 로그가 뜨는지 봅니다. 로그가 없으면 업로드 문제입니다.
2. 빨간 버튼을 눌러 봅니다. 버튼으로 경고가 켜지면 **코드는 정상, 센서 문제**입니다.
3. 버튼도 안 되면 버튼 다리 위치를 확인합니다. 4핀 택트 스위치는 마주 보는 두 다리가
   이미 붙어 있으므로 **대각선 두 다리**를 써야 합니다.

## IR 센서

| 증상 | 원인 | 조치 |
|---|---|---|
| 아무것도 없는데 계속 감지됨 | 센서 출력 논리가 반대 | `IR_ACTIVE_LOW`를 `false`로 |
| 손을 대도 감지가 안 됨 | 감지 거리 설정 | 센서 뒷면 **파란색 가변저항**을 돌려 조정(설계 기준 30cm) |
| 감지가 됐다 안 됐다 함 | 신호 튐 | `ENTRY_CONFIRM_MS`를 늘림(120 → 200) |
| 반응이 너무 느림 | 확정 시간이 김 | `ENTRY_CONFIRM_MS`를 줄임(120 → 60) |
| 한쪽 센서만 반응 | 쌍 판정 옵션 | `ENTRY_REQUIRE_BOTH`가 `true`면 `false`로 |
| 검은 옷·검은 물체를 못 잡음 | 적외선 반사가 약함 | IR 센서의 물리적 한계. 센서 각도를 낮추거나 감도를 올림 |

> 통과 감지 쌍(D4/D5)에는 `EXIT_*` 상수가 같은 방식으로 적용됩니다.

## LED 스트립 (네오픽셀)

| 증상 | 원인 | 조치 |
|---|---|---|
| 전혀 안 켜짐 | **공통 접지 누락** | 외부 전원 GND와 아두이노 GND를 반드시 연결 |
| 첫 몇 개만 켜짐 | 픽셀 수 설정이 실제보다 적음 | LED 알을 세어 `STRIP1_PIXELS` / `STRIP2_PIXELS` 수정 |
| 뒤쪽이 안 켜지거나 색이 이상함 | 전류 부족 | `STRIP_BRIGHTNESS`를 낮추거나 외부 전원 용량을 늘림 |
| 밝기가 불규칙하게 떨림 | 전류 부족 | 위와 동일. 아두이노 5V 핀에서 전원을 뽑고 있지 않은지 확인 |
| 색이 빨강이 아니라 초록/파랑 | 스트립 색 순서(GRB/RGB) 차이 | `WARN_COLOR_R/G/B` 값을 실물에 맞게 바꿔서 빨강이 나오는 조합을 찾음 |
| 흐르는 방향이 반대 | 스트립을 반대로 부착 | `STRIP1_REVERSE` / `STRIP2_REVERSE`를 `true`로 |
| 너무 빠르거나 느림 | 애니메이션 속도 | `ANIM_STEP_MS` 조정(작을수록 빠름) |
| 꼬리가 너무 짧음/김 | 꼬리 길이 | `COMET_LENGTH` 조정 |

> ⚠️ 네오픽셀은 픽셀 1개당 최대 60mA까지 씁니다. 픽셀이 많으면 아두이노 5V 핀으로는
> 절대 부족하며, 무리하게 뽑으면 보드가 재부팅되거나 손상될 수 있습니다.

## 부저

| 증상 | 원인 | 조치 |
|---|---|---|
| 소리가 전혀 안 남 | **능동(active) 부저 사용** | 코드가 `tone()`을 쓰므로 **수동(passive) 부저**가 필요 |
| 소리가 안 남 (수동 부저인데도) | 극성 | `+`가 `D9`, `−`가 `GND`인지 확인 |
| 소리가 너무 낮음/높음 | 주파수 | `BUZZER_FREQ_HZ` 조정 |
| 소리를 아예 끄고 싶음 | — | `BUZZER_FREQ_HZ`를 `0`으로 |
| 스트립이 켜질 때 소리가 미세하게 떨림 | 네오픽셀 출력 중 인터럽트가 잠깐 꺼짐 | 정상 동작. 실제 청감에는 영향 없음 |

## 상태 전환

| 증상 | 원인 | 조치 |
|---|---|---|
| 경고가 켜지자마자 꺼짐 | 진입 센서가 통과 센서까지 함께 건드림 | 센서 쌍을 더 떨어뜨리고, `WARNING_MIN_MS`를 늘림 |
| 초록 버튼이 바로 안 먹음 | 최소 유지 시간 | 정상 동작. 경고 시작 후 3초 뒤부터 종료 신호를 받음 |
| 경고가 안 꺼짐 | 통과 센서 미감지 | 초록 버튼으로 종결, 60초 후 자동 복귀 여부 확인 |
| 60초 자동 복귀를 없애고 싶음 | — | `WARNING_TIMEOUT_MS`를 `0`으로 |
| 버튼 한 번에 여러 번 반응 | 채터링 | `BUTTON_DEBOUNCE_MS`를 늘림(40 → 80) |

## 시뮬레이터

- **Tinkercad에서는 이 스케치가 그대로 동작하지 않습니다.** Tinkercad는
  `Adafruit_NeoPixel` 라이브러리를 지원하지 않습니다.
- 시뮬레이터로 로직만 보려면 스트립 부분을 일반 LED로 바꾼 **별도 스케치**가 필요합니다.
  (아직 작성하지 않았습니다.)

## 발표 당일 비상 대응

| 상황 | 대응 |
|---|---|
| 센서가 현장 조명 때문에 오작동 | **빨강·초록 버튼으로 수동 시연**. 센서와 완전히 같은 로직이 실행됩니다 |
| 스트립 전원이 부족 | `STRIP_BRIGHTNESS`를 낮춰 다시 업로드 |
| 회로가 아예 안 켜짐 | 미리 찍어 둔 **경고 작동 영상**으로 대체 시연 |

> 발표 전에 반드시 대기 → 경고 → 복귀 전체 흐름을 **영상으로 1회 촬영**해 두세요.
