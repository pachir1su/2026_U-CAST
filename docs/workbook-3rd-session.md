## 6. 시연 시나리오

### 작동 순서 (원본에서 6번 칸이 비어 있었습니다)

| 순서 | 작동 내용 |
|:--:|---|
| 1 | 대기 상태. 보행자가 인도 위를 정상 이동할 때는 대기 모드를 유지하며 부저와 LED가 작동하지 않는다 |
| 2 | 자동: 보행자가 차도 경계선에 다가서면 IR 적외선 센서가 이를 감지한다 / 수동: 빨간색 버튼을 누르면 무단횡단으로 판단한다 |
| 3 | 감지 즉시 부저에서 경고음이 울리고, 빨간색 LED 경고등이 점멸하며, 차도 위 LED 스트립 2개가 횡단보도 방향으로 흐르듯 점등되어 운전자에게 보행자가 건너는 중임을 알린다 |
| 4 | 자동: 보행자가 길을 다 건너 반대편 IR 센서 한 쌍을 지나치면 상황 종결을 감지한다 / 수동: 초록색 버튼을 누른다 |
| 5 | 복귀. 부저와 LED 작동이 모두 종료되고 다시 대기 상태로 돌아간다 |
| **6** | **안전장치. 종료 신호가 들어오지 않아도 60초가 지나면 자동으로 대기 상태로 복귀한다** |

### 발표 때 꼭 보여줄 장면

| 항목 | 작성 내용 |
|---|---|
| 발표 때 꼭 보여줄 장면 | ① 대기 상태에서 아무 소리도 빛도 없는 모습 → ② 빨간색 버튼(또는 IR 센서 앞에 손)으로 무단횡단 상황을 만드는 순간 → ③ 부저 경고음 + 빨간색 LED 점멸 + 차도 스트립 2개가 횡단보도 방향으로 흐르는 장면 (**이 장면이 우리 팀의 핵심**) → ④ 초록색 버튼으로 상황을 종결시켜 모든 출력이 한 번에 꺼지고 대기 상태로 돌아가는 모습 |

## 7. AI 1차 코드 제작

### AI에게 입력할 실제 프롬프트

> 우리 팀은 아두이노로 **무단횡단 방지 시스템**을 만들려고 해.
>
> 사용할 부품은 **아두이노 우노 1개, 브레드보드 1개, 점퍼선, 적외선(IR) 센서 4개,
> 네오픽셀 LED 스트립 2개, 부저 1개, 빨간색 LED 1개(220~330Ω 저항), 버튼 2개(빨강·초록),
> 외부 전원 장치 1개**야. 초음파 센서와 압력 센서(FSR), 펜스는 이번 프로젝트에서 제외했어.
>
> 작동 순서는 다음과 같아.
> 1. 차도 경계선을 향한 **IR 센서 한 쌍(2개)** 이 보행자가 차도 쪽으로 접근하는 것을 감지한다.
> 2. 감지가 일정 시간(약 0.1초) 이상 유지되면 아두이노가 무단횡단 상황으로 판단한다.
> 3. **부저가 경고음을 내고, 빨간색 LED가 점멸하고, 차도 위 네오픽셀 스트립 2개가
>    횡단보도 방향으로 흐르듯 순차 점등**되어 운전자에게 보행자가 건너는 중임을 알린다.
> 4. 반대편에 설치한 **다른 IR 센서 한 쌍(2개)** 이 보행자의 통과를 감지하면
>    모든 출력을 끄고 원래 대기 상태로 돌아간다.
>
> 추가 조건도 지켜줘.
> - 센서가 동작하지 않을 때를 대비해, **빨간 버튼을 누르면 2번과 같은 상황으로 판단**하고
>   **초록 버튼을 누르면 4번과 같은 종결 처리**가 되게 해줘. 발표 시연에 쓸 거야.
> - `delay()`로 멈추지 말고 `millis()`를 써서, 경고 중에도 센서와 버튼 입력을 계속 읽게 해줘.
> - 경고가 시작되면 최소 몇 초 동안은 종료 신호를 무시해서, 진입 센서가 통과 센서까지
>   건드려 곧바로 꺼지는 것을 막아줘.
> - 종료 신호가 안 들어와도 일정 시간이 지나면 자동으로 대기 상태로 돌아가게 해줘.
> - **나중에 조정해야 할 값(핀 번호, 스트립 픽셀 수, 밝기, 색상, 감지 확정 시간, 경고 유지 시간,
>   부저 음 높이, 깜빡임 간격 등)은 전부 코드 맨 위에 상수로 모아줘.** 아직 부품을 안 받아서
>   실제 개수를 몰라. 숫자만 바꾸면 되게 만들어줘.
>
> 아두이노 초보자도 이해할 수 있도록
> 1) 회로 연결 핀 2) 전체 코드 3) 코드 설명 4) 수정해야 할 기준값
> 을 나누어 알려줘.

### AI 코드 작성 결과

| 항목 | 작성 내용 |
|---|---|
| AI가 만들어준 코드 | 저장소의 `main.ino` (전체 코드). 상태 기계(대기 ↔ 경고) 방식으로 작성되어 있고, `delay()` 없이 `millis()`로 동작한다 |
| 코드에서 수정해야 할 기준값 | ① `STRIP1_PIXELS` / `STRIP2_PIXELS` — 실제 스트립 LED 개수로 **반드시** 수정<br>② `IR_ACTIVE_LOW` — 센서가 반대로 동작하면 `false`로<br>③ `ENTRY_CONFIRM_MS` (기본 120) — 반응이 느리면 줄이고, 헛감지가 잦으면 늘림<br>④ `WARNING_MIN_MS` (기본 3000) — 경고가 너무 빨리 꺼지면 늘림<br>⑤ `STRIP_BRIGHTNESS` (기본 120) — 전원이 부족해 깜빡이면 낮춤<br>⑥ `ANIM_STEP_MS` (기본 60) — 스트립이 흐르는 속도<br>⑦ `BUZZER_FREQ_HZ` (기본 2000) — 경고음 높낮이 |
| 코드에서 이해가 필요한 부분 | ① **왜 `delay()`를 안 쓰는가** — `delay(1000)`을 쓰면 그 1초 동안 버튼·센서 입력을 아예 못 읽는다. 그래서 "지금 시각"을 알려주는 `millis()`로 시간을 재고, 정해진 시간이 지났는지만 매번 확인한다.<br>② **`HoldFilter` (센서 확정 필터)** — 센서 신호가 잠깐 튀는 것을 무시하고, 같은 값이 정해진 시간 이상 유지될 때만 진짜 감지로 인정한다.<br>③ **`buttonPressedEdge` (버튼 엣지 감지)** — 버튼을 "누르고 있는 동안" 계속 반응하면 안 되므로, "안 눌림 → 눌림"으로 바뀌는 그 순간에만 1번 반응한다.<br>④ **`INPUT_PULLUP`** — 아두이노 내부 저항을 켜서, 버튼을 안 누르면 HIGH·누르면 LOW가 되게 한다. 그래서 버튼에 저항을 따로 안 달아도 된다.<br>⑤ **혜성(comet) 애니메이션** — 밝은 점 하나와 그 뒤로 점점 어두워지는 꼬리를 그린 뒤, 위치를 한 칸씩 옮겨서 흐르는 것처럼 보이게 한다. |

## 8. 코드 기반 핀 연결표

| 부품 | 코드에 나온 핀 번호 | 역할 |
|---|:--:|---|
| 적외선 센서 (IR) 1 | **D2** | 차도 경계선 접근(무단횡단 진입) 감지 — 쌍 A |
| 적외선 센서 (IR) 2 | **D3** | 차도 경계선 접근(무단횡단 진입) 감지 — 쌍 B |
| 적외선 센서 (IR) 3 | **D4** | 반대편 통과(상황 종결) 감지 — 쌍 A |
| 적외선 센서 (IR) 4 | **D5** | 반대편 통과(상황 종결) 감지 — 쌍 B |
| 스트립 LED 1 (네오픽셀) | **D6** | 차도 위 경고 조명 (운전자에게 알림) |
| 스트립 LED 2 (네오픽셀) | **D7** | 차도 위 경고 조명 (운전자에게 알림) |
| 빨간색 LED | **D8** | 운전자 경고등 (220~330Ω 저항 필요) |
| 부저 | **D9** | 경고음. **능동 부저**가 아니라 **수동 부저**를 써야 한다 (코드에서 `tone()`으로 음 높이를 지정하기 때문) |
| 빨간색 버튼 A | **D10** | 수동 발동 (무단횡단 발생 가정) |
| 초록색 버튼 A | **D11** | 수동 종결 (다 건넜다고 가정) |

> 원본 워크북 메모 **"센서가 한 개가 아니라 여러 개입니다. 따라서 여러 개의 핀 번호가
> 필요하다고 사료됩니다."** → IR 센서 4개를 **D2~D5** 로 배정하여 해결했습니다.
> 스트립도 2개이므로 두 번째 스트립을 **D7** 에 추가했습니다.

## 9. 4차시 제작 체크리스트

| 항목 | 작성 내용 |
|---|---|
| 다음 차시에 가장 먼저 확인할 센서 | **IR 적외선 센서**. 4개 중 진입 감지용 한 쌍(D2, D3)을 먼저 연결하고, 시리얼 모니터(9600 baud)를 열어 손을 30cm 앞에 댔을 때 값이 바뀌는지 확인한다. 값이 반대로 나오면 `IR_ACTIVE_LOW`를 `false`로 바꾼다. 센서 뒷면 파란색 가변저항으로 감지 거리를 먼저 맞춘다 |
| 다음 차시에 가장 먼저 작동시킬 출력 장치 | **부저와 빨간색 LED**. 배선이 단순해서 코드가 도는지 가장 빨리 확인할 수 있다. 그다음 LED 스트립 1개(D6), 마지막으로 스트립 2개를 함께 연결한다 |
| 먼저 테스트할 기능 | **수동 버튼 2개로 대기 ↔ 경고 상태가 오가는지**를 가장 먼저 본다. 버튼이 되면 코드 전체 흐름은 정상이므로, 이후 문제는 전부 센서 배선·감도 문제로 좁혀진다 |
| 회로 연결 담당 | (팀에서 직접 정하기) |
| 코드 수정 담당 | (팀에서 직접 정하기) |
| 작동 테스트 담당 | (팀에서 직접 정하기) |
| 사진/영상 기록 담당 | (팀에서 직접 정하기) |
| 오늘 안에 꼭 정리해야 할 것 | ① LED 스트립의 **실제 픽셀(LED) 개수**를 세어서 `STRIP1_PIXELS` / `STRIP2_PIXELS`에 입력<br>② 외부 전원(보조배터리 또는 9V 건전지) 준비 및 **공통 접지** 확인<br>③ 부저가 수동 부저인지 확인<br>④ 대기 → 경고 → 복귀 전체 흐름을 **영상으로 1회 촬영** (5차시 발표자료용)<br>⑤ 잘 안 된 부분을 오류·개선 기록표에 적기 |

| 사용한 센서와 장치 | 아두이노 우노, 적외선(IR) 센서 4개, 네오픽셀 LED 스트립 2개, 부저, 빨간색 LED, 수동 조작용 버튼 2개, 외부 전원 장치 |
| 기대 효과 | ① 운전자가 보행자를 **보이기 전에 먼저 인지**하여 급제동과 추돌 사고를 줄일 수 있습니다.<br>② 보행자에게는 경고음으로 위험을 알려 무단횡단 자체를 줄입니다.<br>③ 사람을 막는 방식이 아니라 **서로에게 알리는 방식**이라, 보행이 불편한 고령자에게 부담을 주지 않습니다.<br>④ 부품이 단순해 실제 골목 교차로나 시장 주변에 적은 비용으로 확대 설치할 수 있습니다. |
| 사진/영상으로 찍어야 할 장면 | ① 완성된 외관 사진 (도로·인도 모형 포함)<br>② 내부 회로 사진 (브레드보드 배선이 보이게)<br>③ 대기 상태 사진 (아무것도 안 켜진 상태)<br>④ **경고 작동 영상** — 스트립이 횡단보도 방향으로 흐르는 장면, 어두운 곳에서 촬영해야 잘 보임<br>⑤ 상황 종결 후 모든 출력이 꺼지는 영상<br>⑥ 팀원들이 제작하는 과정 사진 |
