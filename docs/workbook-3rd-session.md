## 3. 핵심 기능 정리

| 구분 | 내용 |
|---|---|
| 핵심 기능 1 | 도로 양쪽 연석의 IR 4개(왼쪽 D8·D9, 오른쪽 D10·D11)로 보행자가 차도로 진입하는 순간을 **어느 방향이든** 감지한다. |
| 핵심 기능 2 | 진입 감지 시 LED 스트립 2줄을 전체 빨간색으로 켜고, 빨간 경고 LED와 부저를 같은 주기로 점멸해 운전자에게 경고한다. |
| 핵심 기능 3 | 출발한 쪽의 **반대편** 연석 IR이 감지하면 횡단이 끝난 것으로 판단하고 모든 출력을 끈다. |
| 수동 조작 | 빨간 버튼은 경고 수동 시작, 초록 버튼은 경고 수동 종료다. |
| 제외할 기능 | 펜스, 압력센서(FSR), 초음파센서, 횡단보도 길 유도, 방향 계산 |
| 제외하는 이유 | 감지 → 경고 → 종료라는 핵심 작동 장면에 집중하고 발표 시연의 안정성을 높이기 위해 제외한다. |

## 6. 시연 시나리오

| 순서 | 작동 내용 |
|:--:|---|
| 1 | 대기 상태. 보행자가 인도 위를 정상 이동할 때는 LED 스트립, 빨간 경고 LED, 부저가 모두 꺼져 있다. |
| 2 | 자동: 보행자가 **어느 쪽 연석에서든** 차도 경계선에 다가서면 그쪽 IR이 감지하고, 반대편을 도착 지점으로 기억한다. 수동: 빨간 버튼을 누르면 무단횡단 상황으로 판단한다. |
| 3 | 감지 즉시 LED 스트립 2줄이 전체 빨간색으로 켜지고, 운전자 경고용 빨간 LED와 부저가 약 0.3초 간격으로 함께 점멸한다. |
| 4 | 자동: 보행자가 길을 다 건너 **반대편 연석의** IR을 지나가면 상황 종결을 감지한다. 수동: 초록 버튼을 누른다. |
| 5 | 복귀: 스트립·빨간 LED·부저가 모두 꺼지고 다시 대기 상태가 된다. |

### 발표 때 꼭 보여줄 장면

> **왼쪽 진입 → LED 스트립 2줄 전체 빨간색 점등과 빨간 LED·부저 점멸 → 오른쪽 도착 →
> 전체 종료**가 이어지는 장면과, 곧바로 **반대 방향(오른쪽 진입 → 왼쪽 도착)** 으로도
> 똑같이 되는 장면, 그리고 빨간·초록 버튼으로 수동 시연하는 장면을 보여준다.

## 7. AI 1차 코드 제작

### AI에게 입력할 실제 프롬프트

> 우리 팀은 아두이노로 **무단횡단방지 시스템**을 만들려고 해.
>
> 사용할 부품은 아두이노 우노, 브레드보드, LED 스트립, 버튼(초록·빨강), 부저,
> 적외선 센서(IR), 빨간색 LED, 저항, 외부전원장치야.
>
> 작동 순서는 다음과 같아.
> 1. 적외선 센서가 무단횡단 하는 사람을 감지한다.
> 2. 무단횡단 하는 사람이 감지되면 아두이노가 작동 상황으로 판단한다.
> 3. 차도 위의 빨간색 LED와 스트립 LED, 부저가 작동해 운전자에게 경고한다.
> 4. 조건이 사라지면 원래 상태로 돌아간다.
>
> 버튼은 수동 조작용이야. 빨간색 버튼은 보행자가 건너고 있다는 의미로 경고를 켜고,
> 초록색 버튼은 다 건넜다는 의미로 경고를 끄는 거야.
> 그리고 적외선 센서는 적어도 4개 이상 사용할 것 같아. 이것도 각각의 핀으로 해줘.
> 스트립은 2줄만 사용할 거야.
>
> 아두이노 초보자도 이해할 수 있도록 1) 회로 연결 핀 2) 전체 코드 3) 코드 설명
> 4) 수정해야 할 기준값 을 나누어 알려줘.

위 인용은 실제로 입력했던 프롬프트 **원문 기록**이라 고치지 않았습니다.
최종 구성은 워크북대로 **스트립 2줄(각 LED 10개)** 입니다. 다만 지금은 1줄만
있어서, 축소판(`test/test.ino`)은 1줄로 두고 `main.ino`의 `PIN_STRIP_2`가 `0`인
동안에는 두 번째 스트립을 건너뜁니다.

### AI 코드 작성 결과

| 항목 | 작성 내용 |
|---|---|
| AI가 만들어준 코드 | 저장소의 `main.ino`. `STATE_IDLE`, `STATE_WARNING` 두 상태만 사용하는 상태 머신이다. 왼쪽(D8·D9) 또는 오른쪽(D10·D11) 어느 쪽이든 먼저 감지된 쪽에서 경고를 시작하고, 그 반대편 감지 또는 초록 버튼(A1)으로 종료한다. 빨간 버튼(A0)은 강제 시작이다. |
| 코드에서 수정해야 할 기준값 | `PIN_STRIP_2`(두 번째 스트립 핀, 아직 미정), `STRIP_1_PIXELS`·`STRIP_2_PIXELS`(각 스트립의 낱개 LED 개수, 현재 10), `WARNING_BLINK_MS = 300`(빨간 LED·부저 점멸 주기), `BUZZER_FREQUENCY_HZ = 1000`, `IR_ACTIVE_LOW`(IR 센서 감지 논리), `IR_CONFIRM_MS`, `STRIP_BRIGHTNESS` |
| 코드에서 이해가 필요한 부분 | `detectedEdge()`는 IR 신호가 `IR_CONFIRM_MS` 이상 유지된 뒤 **감지로 바뀌는 순간만 한 번** 처리하므로, 센서가 계속 가려져 있어도 이벤트가 반복되지 않는다. `buttonPressedEdge()`는 버튼을 길게 눌러도 한 번만 처리한다. 스트립은 경고 동안 계속 켜져 있고, 빨간 LED와 부저만 점멸한다. `startedFrom`은 이번 횡단이 어느 쪽에서 시작됐는지 기억해 두고, 그 **반대편** 센서가 감지될 때만 종료한다(양방향). |

> 워크북 원본 1차 코드와 달라진 점: `delay()` 없이 동작하도록 확정 시간 필터와
> 버튼 디바운싱, 엣지 처리를 추가했습니다. 시작·종료 판정 기준은 원본과 같습니다.

## 10. 발표자료 메모

| 발표자료 항목 | 작성 내용 |
|---|---|
| 문제 상황 한 문장 | 천안중앙시장 주변에서는 고령 보행자가 사각지대에서 갑자기 차도로 진입해 운전자가 뒤늦게 급제동하는 위험이 발생한다. |
| 사용자 불편 한 문장 | 보행자는 차량에 자신의 존재를 알리기 어렵고, 운전자는 보행자가 도로에 들어온 뒤에야 발견할 수 있다. |
| 우리 팀 해결 아이디어 한 문장 | 도로 양쪽 연석의 IR 중 먼저 감지된 쪽에서 경고를 시작하고, 반대편 IR이 감지되면 상황이 끝난 것으로 보고 경고를 종료한다. |
| 작동 원리 한 문장 | 도로 양쪽 연석의 IR 중 먼저 감지된 쪽을 출발 지점으로 보고 LED 스트립과 빨간 LED·부저로 운전자에게 경고하며, 반대편 IR이 감지되면 다 건넌 것으로 판단해 모든 출력을 끄고 대기로 돌아간다(양방향). |
| 사용한 센서와 장치 | Arduino Uno, IR 센서 4개, 네오픽셀 스트립 2개(각 LED 10개), 빨간 경고 LED, 부저, 수동 조작 버튼 2개, 외부 5V 전원 |
| 기대 효과 | 운전자가 도로 위 보행자를 더 빨리 인지해 급제동과 충돌 위험을 줄인다. 시장 주변과 먹자골목 등에도 적용할 수 있다. |
| 사진/영상으로 찍어야 할 장면 | 완성 모형, IR 4개 설치 위치, 진입 감지 시 경고 시작, 통과 감지 시 경고 종료, 버튼 수동 시연, 전체 회로와 공통 접지 |
