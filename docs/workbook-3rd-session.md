## 1. 우리 팀이 만들 장치 한눈에 보기

| 항목 | 작성 내용 |
|---|---|
| 우리 팀이 해결하려는 문제 | 천안중앙시장 주변에서 보행자가 사각지대에서 갑자기 차도로 진입했을 때 운전자가 늦게 발견하는 위험을 줄인다. |
| 이 문제를 겪는 사람 | 천안중앙시장을 이용하는 보행자와 주변 도로 운전자 |
| 문제가 발생하는 장소 | 천안 중앙시장과 중앙동 일대, 먹자골목 등 보행자와 차량이 섞이는 구간 |
| 문제가 발생하는 상황 | 시장 출입구와 주정차 차량 사이에서 보행자가 갑자기 도로로 진입하고, 운전자가 뒤늦게 발견하는 상황 |
| 가장 불편하거나 위험한 순간 | 짐이 많거나 보행이 불편한 사람이 횡단보도까지 우회하지 않고 가까운 곳에서 도로를 건너려는 순간 |
| 우리 팀이 만들 장치 | 각 구간의 **시작 IR → LED 스트립 → 끝 IR**을 한 세트로 묶어, 구간별로 독립 작동하는 돌발 보행자 감지·경고 장치 |

> 이 장치는 보행자의 횡단을 물리적으로 막는 장치가 아닙니다. 이미 도로에 진입한 위험 상황을 더 빨리 알리는 **2차 사고 예방용 경고 장치**입니다.

## 2. MVP 제작 기준서

| 항목 | 작성 내용 |
|---|---|
| 우리 팀 아이디어 이름 | 멈춰 ! |
| 프로젝트 설명 | 돌발 보행자 감지 및 경고 시스템 |
| 핵심 구조 | **IR 센서 2개 + LED 스트립 1개 = 독립 채널 1세트** |
| 채널 1 | 시작 IR 1(D8) → 스트립 1(D4) 점멸 시작 → 끝 IR 1(D10) → 스트립 1 점멸 종료 |
| 채널 2 | 시작 IR 2(D9) → 스트립 2(`PIN_STRIP_2`) 점멸 시작 → 끝 IR 2(D11) → 스트립 2 점멸 종료 |
| 동시 작동 | 채널 1과 채널 2는 서로 독립적이며 동시에 작동할 수 있음 |
| 공용 경고 | 하나 이상의 채널이 작동하면 빨간 경고 LED(D3) 점멸 및 부저(D5) 사이렌 작동 |
| 수동 시연 | 빨간 버튼(A0) = 두 채널 수동 시작, 초록 버튼(A1) = 두 채널 수동 종료 |
| 확장성 | IR 한 쌍과 스트립을 추가하면 독립 채널을 같은 방식으로 확장 가능 |
| 이번 프로젝트에서 제외 | 펜스, 압력센서(FSR), 초음파센서, 길 유도, 방향성 흐름 애니메이션 |
| 제외하는 이유 | 초음파센서는 역할이 불분명하고 펜스는 시선이 분산된다. 길 유도와 방향 계산은 MVP 범위를 넘어 제작과 시연 난도를 크게 올린다. |
| 나중에 개선하고 싶은 기능 | 정류장을 제외한 구간의 펜스와 스크린도어, 차량 접근 감지, 다중 보행자 처리, TAAS 기반 설치 지점 선정 |

두 번째 스트립의 실제 DIN 핀은 아직 확정되지 않았으므로 `PIN_STRIP_2 = 0`이 기본입니다.
실물 배선이 결정될 때만 해당 값을 실제 핀으로 변경합니다.

## 3. 핵심 기능 정리

| 구분 | 내용 |
|---|---|
| 채널별 시작 | 각 채널의 시작 IR이 감지되면 **그 채널만** 경고 상태가 됨 |
| 채널별 출력 | 활성 채널에 연결된 LED 스트립만 300ms 간격으로 빨간색 점멸 |
| 채널별 종료 | 같은 채널의 끝 IR이 감지되면 **그 채널만** 종료 |
| 독립 동작 | 한 채널이 종료되어도 다른 채널이 활성 상태라면 다른 채널의 스트립과 공용 경고는 계속 동작 |
| 공용 빨간 LED | 하나 이상의 채널이 활성 상태일 때 300ms 간격으로 점멸 |
| 공용 부저 | 하나 이상의 채널이 활성 상태일 때 800Hz↔1800Hz 사이렌을 연속 출력 |
| 비차단 처리 | `delay()` 없이 `millis()` 기준으로 점멸과 사이렌을 갱신하여 센서 입력을 계속 읽음 |

## 4. 입력-처리-출력 작동 설계서

| 기능 | 입력 | 처리 | 출력 |
|---|---|---|---|
| 채널 1 시작 | 시작 IR 1(D8) | 채널 1 활성화 | 스트립 1(D4) 점멸 시작, 공용 LED·부저 활성 |
| 채널 1 종료 | 끝 IR 1(D10) | 채널 1 비활성화 | 스트립 1 종료. 채널 2가 활성이라면 공용 경고 유지 |
| 채널 2 시작 | 시작 IR 2(D9) | 채널 2 활성화 | 스트립 2 점멸 시작, 공용 LED·부저 활성 |
| 채널 2 종료 | 끝 IR 2(D11) | 채널 2 비활성화 | 스트립 2 종료. 채널 1이 활성이라면 공용 경고 유지 |
| 빨간 버튼 | A0 | 두 채널을 수동 활성화 | 연결된 스트립 및 공용 경고 시작 |
| 초록 버튼 | A1 | 두 채널을 수동 비활성화 | 모든 경고 출력 종료 |
| 오입력 방지 | 한 채널의 시작·끝 IR이 동시에 감지되거나 끝 IR이 이미 감지 중 | 해당 채널 시작을 보류하고 로그 출력 | 현재 상태 유지 |

## 6. 시연 시나리오

### 채널 1 단독 시연

1. 모든 출력이 꺼진 상태에서 시작합니다.
2. 시작 IR 1(D8)을 감지시킵니다.
3. 스트립 1(D4)과 빨간 경고 LED가 약 0.3초 간격으로 점멸하고 부저가 사이렌을 냅니다.
4. 끝 IR 1(D10)을 감지시키면 채널 1이 종료되고, 다른 채널이 비활성이라면 공용 LED와 부저도 꺼집니다.

### 독립 동시 작동 시연

1. 채널 1을 시작합니다.
2. 채널 1이 작동 중인 상태에서 시작 IR 2(D9)를 감지시켜 채널 2도 시작합니다.
3. 끝 IR 1(D10)을 감지시키면 **스트립 1만 종료**되고 스트립 2와 공용 경고는 계속 작동합니다.
4. 끝 IR 2(D11)을 감지시키면 나머지 출력까지 모두 종료됩니다.

> 두 번째 스트립 핀이 아직 확정되지 않은 단계에서는 채널 2 센서 상태만 코드·시리얼 로그로 검증하고, 실제 스트립 2 출력은 최종 핀 확정 후 확인합니다.

## 7. AI 1차 코드 제작

### AI에게 입력할 실제 프롬프트

> 우리 팀은 아두이노로 **무단횡단방지 시스템**을 만들려고 해.
>
> 사용할 부품은 아두이노 우노, 브레드보드, LED 스트립, 버튼(초록·빨강), 부저,
> 적외선 센서(IR), 빨간색 LED, 저항, 외부전원장치야.
>
> 작동 순서는 다음과 같아.
> 1. 적외선 센서가 무단횡단 하는 사람을 감지한다.
> 2. 무단횡단 하는 사람이 감지되면 아두이노가 작동 상황으로 판단한다.
> 3. 차도 위의 빨간색 LED와 스트립 LED, 부저가 작동해 운전자에게 경고한다.
> 4. 조건이 사라지면 원래 상태로 돌아간다.
>
> 버튼은 수동 조작용이야. 빨간색 버튼은 보행자가 건너고 있다는 의미로 경고를 켜고,
> 초록색 버튼은 다 건넜다는 의미로 경고를 끄는 거야.
> 그리고 적외선 센서는 적어도 4개 이상 사용할 것 같아. 이것도 각각의 핀으로 해줘.
> 스트립은 2줄만 사용할 거야.
>
> 아두이노 초보자도 이해할 수 있도록 1) 회로 연결 핀 2) 전체 코드 3) 코드 설명
> 4) 수정해야 할 기준값 을 나누어 알려줘.


위 인용은 실제로 입력했던 프롬프트 **원문 기록**이라 고치지 않았습니다. 인용문 안의
"무단횡단방지 시스템"이라는 옛 이름도 이 역사적 기록의 일부로 그대로 남깁니다.
현재 최종 설계는 이후 이슈 #18에서 명확해진 요구에 따라 **독립 채널 방식**으로 정리했습니다.

최종 구성은 워크북대로 **스트립 2줄(각 LED 10개)**입니다. 다만 지금은 1줄만 있어서,
축소판(`test/test.ino`)은 1줄로 두고 `main.ino`의 `PIN_STRIP_2`가 `0`인 동안에는
두 번째 스트립을 건너뜁니다.

### 현재 코드 작성 결과

| 항목 | 작성 내용 |
|---|---|
| 최종 코드 | `main.ino` — 채널 1과 채널 2의 활성 상태를 별도로 보관하고 각 시작·끝 IR이 자기 스트립만 제어함 |
| 축소판 코드 | `test/test.ino` — 시작 D8 / 끝 D9 / 스트립 D4 한 채널만 사용하는 실물 테스트판 |
| 스트립 점멸 | `WARNING_BLINK_MS = 300`, 활성 채널의 스트립과 공용 빨간 LED가 같은 점멸 위상 사용 |
| 부저 사이렌 | 800Hz↔1800Hz, 상승·하강 각 500ms, 25ms마다 주파수 갱신 |
| 두 번째 스트립 | `PIN_STRIP_2_VALUE = 0` 기본. 핀 확정 전에는 출력만 건너뜀 |
| 진단 로그 | 채널별 IR 원시값·판정, CH1/CH2 상태, 스트립·LED·부저 상태 출력 |

## 9. 4차시 제작 체크리스트

| 항목 | 작성 내용 |
|---|---|
| 먼저 확인할 센서 | 시작 IR과 끝 IR이 각각 안정적으로 HIGH/LOW를 바꾸는지 |

| 기록 | 채널 1 단독, 채널 2 단독, 두 채널 동시 작동 영상을 각각 촬영 |

| 차별점 | 여러 구간을 독립적으로 추가할 수 있으며 동시에 보행자가 진입해도 채널별로 따로 작동함 |
| 한계 설명 | 보행을 강제로 차단하는 장치가 아니라 위험 상황 인지 시간을 앞당기는 경고 장치 |
| 기대 효과 | 운전자와 보행자가 위험 상황을 더 빨리 인지해 급제동·충돌 위험을 낮추는 데 도움 |
