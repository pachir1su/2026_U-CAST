## 1. 우리 팀이 만들 장치 한눈에 보기

| 항목 | 작성 내용 |
|---|---|
| 우리 팀이 해결하려는 문제 | 천안중앙시장 주변에서 고령 보행자가 사각지대에서 갑자기 차도로 진입해 발생하는 무단횡단 위험을 줄인다. |
| 이 문제를 겪는 사람 | 천안중앙시장을 이용하는 65세 이상 고령 보행자와 주변 도로 운전자 |
| 문제가 발생하는 장소 | 천안 중앙시장과 중앙동 일대, 충남 천안시 동남구 사직동 290 부근 |
| 문제가 발생하는 상황 | 시장 출입구와 주정차 차량 사이에서 보행자가 갑자기 도로로 진입하고, 운전자가 늦게 발견해 급제동하는 상황 |
| 가장 불편하거나 위험한 순간 | 짐이 많거나 보행이 불편한 고령자가 횡단보도까지 우회하지 않고 가까운 곳에서 도로를 건너려는 순간 |
| 우리 팀이 만들 장치 | 양쪽 인도의 IR 감지선으로 보행자의 출발과 도착을 판정하고, 횡단 중 도로 LED와 `보행자 주의` 표지판을 점멸하는 시스템 |

## 3. 핵심 기능 정리

| 구분 | 내용 |
|---|---|
| 핵심 기능 1 | IR 브레이크빔 2세트를 양쪽 인도에 설치해 보행자가 각 인도의 차도 진입 구간을 통과하는 순간을 감지한다. |
| 핵심 기능 2 | 대기 상태에서 왼쪽 감지선이 먼저 끊기면 왼쪽→오른쪽, 오른쪽 감지선이 먼저 끊기면 오른쪽→왼쪽 횡단으로 판정한다. |

| 제외할 기능 | 횡단보도 유도, 초음파센서, 펜스, 압력센서, 레이저 |
| 제외하는 이유 | 감지·경고·종료의 핵심 작동 장면에 집중하고 제작과 발표 시연의 안정성을 높이기 위해 제외한다. |

## 4. 입력-처리-출력 작동 설계서

| 기능 이름 | 입력 | 처리 | 출력 |
|---|---|---|---|
| 왼쪽→오른쪽 횡단 감지 | 대기 상태에서 왼쪽 IR 빔 차단 또는 빨간 버튼 입력 | 왼쪽 인도를 출발 지점으로 저장하고 `왼쪽→오른쪽 횡단 중` 상태로 변경 | 도로 LED 스트립 2개와 표지판 빨간 LED 점멸, 부저 경고 |
| 오른쪽→왼쪽 횡단 감지 | 대기 상태에서 오른쪽 IR 빔 차단 또는 초록 버튼 입력 | 오른쪽 인도를 출발 지점으로 저장하고 `오른쪽→왼쪽 횡단 중` 상태로 변경 | 도로 LED 스트립 2개와 표지판 빨간 LED 점멸, 부저 경고 |
| 반대편 도착 및 종료 | 왼쪽→오른쪽 횡단 중 오른쪽 IR 입력 또는 오른쪽→왼쪽 횡단 중 왼쪽 IR 입력 | 출발 방향의 반대편에 도착한 것으로 판단 | 모든 LED와 부저 종료, 대기 상태 복귀 |
| 오입력 방지 | 같은 쪽 센서 반복 입력, 양쪽 동시 입력, 너무 빠른 도착 입력 | 같은 쪽 반복은 무시하고 양쪽 동시는 방향 판정 불가로 무시하며, 최소 횡단시간 전 도착 신호는 받지 않음 | 현재 상태 유지 및 시리얼 로그 출력 |
| 안전 자동 복귀 | 횡단 시작 후 반대편 도착 신호가 장시간 없음 | 설정한 최대 시간이 지나면 센서 누락으로 판단 | 모든 출력 종료, 대기 상태 복귀 |

> 왼쪽→오른쪽과 오른쪽→왼쪽 두 방향에서 각각 **첫 번째 인도 감지 → 도로 LED·표지판·부저 경고 → 반대편 인도 감지 → 전체 종료**가 작동하는 장면과, 버튼으로 동일한 입력을 모의하는 비상 시연을 보여준다.

## 7. AI 1차 코드 제작

### AI에게 입력할 실제 프롬프트

> 우리 팀은 Arduino Uno로 **IR 기반 양방향 무단횡단 경고 시스템**을 만들려고 해.
>
> 사용할 부품은 Arduino Uno 1개, IR 브레이크빔 센서 2세트(송신부 2개+수신부 2개),
> 네오픽셀 LED 스트립 2개, `보행자 주의` 표지판 내부 빨간 LED 1개, 수동 부저 1개,
> 버튼 2개, 외부 5V 전원이야.
>
> 왼쪽 IR 수신부는 D2, 오른쪽 IR 수신부는 D3, 스트립은 D6·D7, 표지판 LED는 D8,
> 부저는 D9, 왼쪽 모의 버튼은 D10, 오른쪽 모의 버튼은 D11에 연결할 거야.
>
> 대기 상태에서 왼쪽 빔이 먼저 끊기면 왼쪽→오른쪽 횡단, 오른쪽 빔이 먼저 끊기면
> 오른쪽→왼쪽 횡단으로 저장해. 횡단 중에는 두 스트립 전체와 표지판 LED를 빨간색으로
> 점멸하고 부저를 간헐적으로 울려. 반대편 빔이 끊기면 모든 출력을 종료해.
>
> 빨간 버튼은 왼쪽 IR, 초록 버튼은 오른쪽 IR이 작동한 것으로 처리해. 버튼 색은 시작·종료가 아니야.
> 같은 쪽 반복 입력은 무시하고, 양쪽 동시 입력은 방향을 알 수 없으므로 무시해.
> 너무 빠른 도착 입력을 막는 최소 횡단시간과 도착 신호 누락 시 자동 복귀 시간을 넣어줘.
> `delay()`는 사용하지 말고 `millis()` 기반 상태 머신으로 작성해.
> 핀 번호와 픽셀 수, 밝기, IR 논리, 신호 확정시간, 점멸·부저 간격, 최소 횡단시간,
> 자동 복귀 시간은 코드 상단 상수로 모아줘.

### AI 코드 작성 결과

| 항목 | 작성 내용 |
|---|---|
| AI가 만들어준 코드 | 저장소의 `main.ino`. `STATE_IDLE`, `STATE_LEFT_TO_RIGHT`, `STATE_RIGHT_TO_LEFT` 상태를 사용하는 양방향 상태 머신이다. |
| 코드에서 수정해야 할 기준값 | `STRIP1_PIXELS`, `STRIP2_PIXELS`, `STRIP_BRIGHTNESS`, `IR_ACTIVE_LOW`, `IR_USE_INTERNAL_PULLUP`, `IR_CONFIRM_MS`, `WARNING_LIGHT_BLINK_MS`, `CROSSING_MIN_MS`, `CROSSING_TIMEOUT_MS`, `BUZZER_*` |
| 코드에서 이해가 필요한 부분 | `blockedEdge()`는 빔이 끊긴 상태가 일정 시간 유지된 뒤 **차단으로 바뀐 순간만 한 번** 처리한다. `buttonPressedEdge()`는 버튼을 누르는 순간만 한 번 처리한다. 상태 머신은 먼저 감지된 쪽을 출발지로 저장하고 반대편 입력만 종료 조건으로 받는다. |

|---|---|
| 문제 상황 한 문장 | 천안중앙시장 주변에서는 고령 보행자가 사각지대에서 갑자기 차도로 진입해 운전자가 뒤늦게 급제동하는 위험이 발생한다. |
| 사용자 불편 한 문장 | 보행자는 차량에 자신의 존재를 알리기 어렵고, 운전자는 보행자가 도로에 들어온 뒤에야 발견할 수 있다. |
| 우리 팀 해결 아이디어 한 문장 | 양쪽 인도의 IR 감지선으로 보행자의 출발과 도착을 판단하고, 횡단 중 도로 LED와 `보행자 주의` 표지판으로 운전자에게 경고한다. |
| 작동 원리 한 문장 | 먼저 끊긴 IR 빔으로 횡단 방향을 저장해 LED와 부저를 작동하고, 반대편 IR 빔이 끊기면 도착으로 판단해 자동 종료한다. |
| 사용한 센서와 장치 | Arduino Uno, IR 브레이크빔 2세트, 네오픽셀 스트립 2개, 표지판 빨간 LED, 수동 부저, 모의 입력 버튼 2개, 외부 5V 전원 |
| 기대 효과 | 운전자가 도로 위 보행자를 더 빨리 인지하고, 보행자도 부저를 통해 진입 위험을 인식하도록 해 급제동과 충돌 위험을 줄인다. 시장 주변과 먹자골목 등에도 적용할 수 있다. |
| 사진/영상으로 찍어야 할 장면 | 완성 모형, IR 송수신 정렬, 왼→오 자동 시연, 오→왼 자동 시연, 표지판 점멸, 차도 스트립 점멸, 버튼 비상 시연, 전체 회로와 공통 접지 |
